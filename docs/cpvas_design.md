## 1. 执行摘要（产品定位）

### 1.1 产品背景

犬只瘙痒（pruritus）是宠物医院最常见的就诊原因之一，但因为犬只无法言语表达，主人往往难以客观量化症状严重程度，导致：

- 就诊时无法向兽医提供准确的症状描述
- 无法有效追踪用药/治疗前后的症状变化
- 轻症被忽视，重症被低估或高估

**C-PVAS** 是一套基于智能宠物项圈的**日粒度瘙痒综合评估系统**，通过传感器客观数据（IMU + 温湿度）与主人行为观察（追问树问卷）相结合，输出 **L0–L10** 标准化评分，为兽医诊断和主人日常监护提供可信依据。

### 1.2 产品定位

| 维度 | 定位说明 |
|------|----------|
| **核心场景** | 家庭健康监护，非户外活动追踪 |
| **数据同步** | 仅在家庭 WiFi 范围内同步，无 GPS/蜂窝网络 |
| **评估节奏** | 每日一次批量评估（非实时评分） |
| **使用对象** | 宠物主人（日常监护）+ 兽医（辅助诊断参考） |
| **最小适用年龄** | 8周龄以上犬只 |
| **核心优势** | 个体动态基线，消除品种/体型/个体差异带来的偏差 |

### 1.3 核心设计原则

1. **个体化基线优先**：所有评分均基于该犬只自身的历史基线，而非群体均值，避免品种偏差
2. **多模态融合**：传感器客观数据 + 主人主观观察，互为补充
3. **置信区间透明**：数据积累不足时明确告知置信区间，不做过度精确的承诺
4. **管线可扩展**：行为分类预留扩展接口，未来可增加更细粒度行为类别

## 2. 数据来源概览

### 2.1 硬件传感器

| 传感器 | 输出字段 | 采样率（建议） | 用途 |
|--------|----------|----------------|------|
| 6轴 IMU | `ax, ay, az`（加速度）<br>`gx, gy, gz`（陀螺仪） | 50 Hz | 行为识别（抓挠/移动/睡眠）、重力向量对齐 |
| 颈部温度传感器 | `neck_temp`（°C） | 1次/分钟 | 局部炎症代理指标（S4） |
| 环境温度传感器 | `env_temp`（°C） | 1次/5分钟 | 环境修正（S6） |
| 环境湿度传感器 | `env_humidity`（%RH） | 1次/5分钟 | 环境修正（S6） |

### 2.2 佩戴状态检测

佩戴状态检测是**所有数据处理的前提**，必须在管线第一步完成。

| 佩戴状态 | 枚举值 | 判断逻辑（示意） | 数据处理策略 |
|----------|--------|-----------------|--------------|
| `NOT_WORN` | 0 | IMU全静止 + 温度接近环境温度 | 该时段数据**完全丢弃** |
| `WORN_LOOSE` | 1 | 重力向量方差超阈值（项圈打滑） | 该时段行为分类**标记为低置信**，不计入评分 |
| `WORN_NORMAL` | 2 | 重力向量稳定，温度高于环境温度 | 正常参与评分 |

> **注意**：一天内有效佩戴时长 `< 12小时` 时，当日评估结果**降级处理**（置信区间扩大一档）。

### 2.3 坐标归一化

由于项圈可能在颈部发生旋转，需要**实时重力向量对齐**，将传感器坐标系统一到设备自然坐标系：

- 读取当前加速度向量 `[ax, ay, az]`，计算重力方向单位向量
- 构建旋转矩阵，将 IMU 原始数据投影到归一化坐标系
- **无需静态校准**，每帧实时计算，对项圈位移具有鲁棒性

### 2.4 主人问卷（追问树）

通过 App 端追问树（见第5节）收集主人观察信息，输出 L0–L10 主观评级，作为 S5 维度输入。

## 3. 数据处理管线

```
原始 IMU + 温湿度数据
        │
        ▼
┌───────────────────────┐
│  Step 1: 佩戴状态检测  │  NOT_WORN → 丢弃
│  (Wear Detection)     │  WORN_LOOSE → 低置信标记
└───────────┬───────────┘
            │ WORN_NORMAL
            ▼
┌───────────────────────┐
│  Step 2: 坐标归一化   │  重力向量对齐，实时旋转矩阵
│  (Coord Normalization)│
└───────────┬───────────┘
            │
            ▼
┌───────────────────────┐
│  Step 3: 行为分类     │  UNKNOWN=0 / MOVEMENT=1
│  (Behavior Classif.)  │  SLEEP=2 / SCRATCH=3
└───────────┬───────────┘
            │
            ▼
┌───────────────────────┐
│  Step 4: 特征提取     │  PEB计算、W-PEB、夜间指标
│  (Feature Extraction) │  颈温统计、环境相关分析
└───────────┬───────────┘
            │
            ▼
┌───────────────────────┐
│  Step 5: 日度评估计算 │  S1–S6 各维度评分
│  (Daily Assessment)   │  个体基线 Z-score 计算
└───────────┬───────────┘
            │
            ▼
┌───────────────────────┐
│  Step 6: 阶段化输出   │  Phase 0/1/2/3 置信区间
│  (Phase-based Output) │  最终 L0–L10 + 置信范围
└───────────────────────┘
```

## 4. 核心概念定义

### 4.1 行为分类枚举

| 枚举值 | 名称 | 含义 |
|--------|------|------|
| `UNKNOWN = 0` | 未知 | 无法归类（如剧烈运动过渡态、数据异常） |
| `MOVEMENT = 1` | 移动 | 行走、奔跑、玩耍等主动运动 |
| `SLEEP = 2` | 睡眠 | 静卧或睡眠状态 |
| `SCRATCH = 3` | 抓挠 | 用爪挠颈部/身体的瘙痒行为 |

> 后续版本将扩展至更细粒度行为（如舔舐、摇头、摩擦等），接口预留扩展位。

### 4.2 PEB（Pruritic Event Bout，瘙痒事件簇）

**定义**：持续时长 ≥ 3秒 的抓挠行为序列，且与**前一次事件**的间隔 ≥ 30秒。

```
判断逻辑：
  scratch_duration ≥ 3s
  AND
  gap_from_previous_event ≥ 30s（或为当日第一次事件）
  → 计为 1 个 PEB
```

| 参数 | 值 | 说明 |
|------|----|------|
| 最小持续时间 | 3秒 | 过滤误触发和短暂偶发 |
| 最小间隔时间 | 30秒 | 合并连续瘙痒，视为同一发作簇 |

### 4.3 强度分级

基于抓挠期间 IMU 信号的幅度特征（加速度均方根或峰值）将每个 PEB 分级：

| 强度等级 | 英文 | 判断阈值（示意） | W-PEB 权重 |
|----------|------|-----------------|------------|
| 轻度 | Light | 幅度 RMS < 阈值_低 | × 1.0 |
| 中度 | Medium | 阈值_低 ≤ RMS < 阈值_高 | × 1.5 |
| 重度 | Heavy | RMS ≥ 阈值_高 | × 2.5 |

> 强度阈值需通过标注数据集（含兽医人工评级）进行校准，当前为工程预估值，**待医疗团队确认**。

### 4.4 W-PEB（Weighted PEB，加权瘙痒事件簇）

```
W-PEB_daily = Σ (Light_count × 1.0) + (Medium_count × 1.5) + (Heavy_count × 2.5)
```

W-PEB 综合反映抓挠的**频次与强度**，比单纯计数更能代表实际瘙痒负担。

### 4.5 个体基线与 Z-score

**个体基线**：使用**指数加权移动平均（EWMA）**维护每只犬的历史均值和标准差：

```
baseline_mean(t) = α × value(t) + (1 - α) × baseline_mean(t-1)
baseline_std(t)  = sqrt(α × (value(t) - baseline_mean(t))² + (1-α) × baseline_std(t-1)²)
```

- 推荐平滑系数 `α = 0.1`（衰减半衰期约10天），具体值待调参
- 基线在 Phase 0（前3天）预热期内**仅积累，不用于评分**

**Z-score 计算**：

```
Z = (current_daily_value - baseline_mean) / baseline_std
```

Z-score 表示当日值偏离个体正常水平的程度，正值表示高于基线，负值表示低于基线。

### 4.6 评估阶段（Phase）

| Phase | 天数范围 | 阶段名称 | 基线状态 | 输出置信区间 |
|-------|----------|----------|----------|--------------|
| Phase 0 | 第1–3天 | 预热期 | 仅积累，不评分 | ±3（如 L4–L10） |
| Phase 1 | 第4–14天 | 早期 | 基线初步建立 | ±2（如 L5–L7） |
| Phase 2 | 第15–30天 | 中期 | 基线逐渐稳定 | ±1（如 L5–L6） |
| Phase 3 | 第31天起 | 稳定期 | 基线充分可信 | 精确单级（如 L6） |

## 5. 评估维度详述

### S1 抓挠频次（25分）

**评估目标**：衡量当日抓挠行为的**发生次数**相对于个体基线的偏离程度。

**数据来源**：

- 行为分类输出中的 SCRATCH 事件
- 经 PEB 规则处理后的当日 PEB 总数
- 个体基线（EWMA 均值和标准差）

**计算公式**：

```
Z_S1 = (daily_PEB_count - baseline_peb_mean) / baseline_peb_std
S1_score = clamp(Z_score_to_points(Z_S1), 0, 25)
```

**Z-score 到分数映射**：

| Z-score 区间 | 含义 | S1 原始分（0–25） |
|-------------|------|------------------|
| Z ≤ -1.0 | 显著低于基线（非常少） | 0 |
| -1.0 < Z ≤ -0.5 | 低于基线 | 3 |
| -0.5 < Z ≤ 0.5 | 接近基线（正常） | 8 |
| 0.5 < Z ≤ 1.0 | 高于基线 | 13 |
| 1.0 < Z ≤ 1.5 | 明显高于基线 | 18 |
| 1.5 < Z ≤ 2.0 | 显著高于基线 | 22 |
| Z > 2.0 | 极度高于基线 | 25 |

**可行性评级**: ★★★ **HIGH**

> 技术依赖：行为分类模型（SCRATCH 类别识别精度）+ PEB 规则引擎。IMU 数据可直接用于抓挠识别，工程实现路径清晰。主要不确定性在于 SCRATCH 分类精度，需标注数据验证。

---

### S2 抓挠强度与时长（25分）

**评估目标**：衡量当日抓挠的**综合负担**（强度 × 次数 × 时长），相对于个体基线的偏离。

**数据来源**：

- 每个 PEB 的强度分级（Light / Medium / Heavy）
- 每个 PEB 的持续时长
- 当日 W-PEB 总分
- 个体基线（W-PEB 的 EWMA）

**计算公式**：

```
W-PEB_daily = Σ(Light×1.0 + Medium×1.5 + Heavy×2.5)
Z_S2 = (W-PEB_daily - baseline_wpeb_mean) / baseline_wpeb_std
S2_score = clamp(Z_score_to_points(Z_S2), 0, 25)
```

**Z-score 到分数映射**（同 S1 映射表，满分 25）：

| Z-score 区间 | S2 原始分（0–25） |
|-------------|------------------|
| Z ≤ -1.0 | 0 |
| -1.0 < Z ≤ -0.5 | 3 |
| -0.5 < Z ≤ 0.5 | 8 |
| 0.5 < Z ≤ 1.0 | 13 |
| 1.0 < Z ≤ 1.5 | 18 |
| 1.5 < Z ≤ 2.0 | 22 |
| Z > 2.0 | 25 |

**强度判断补充说明**：

| 分析指标 | 计算方式 | 意义 |
|----------|----------|------|
| 加速度 RMS | `sqrt(mean(ax²+ay²+az²))` 在 SCRATCH 窗口内 | 反映抓挠力度 |
| 陀螺仪峰值 | `max(|gx|, |gy|, |gz|)` | 反映抓挠动作幅度 |
| 持续时长 | PEB 结束时间戳 - 开始时间戳 | 反映抓挠持续性 |

**可行性评级**: ★★★ **HIGH**

> 强度分级依赖 IMU 信号质量，理论可行性高，但强度阈值（Light/Medium/Heavy 分界）需要通过带标注的真实数据校准。建议与 S1 共用同一批标注数据集。

---

### S3 夜间静息质量（20分）

**评估目标**：评估犬只在**夜间静息窗口（22:00–06:00）**内的睡眠质量，夜间抓挠和睡眠中断是瘙痒严重程度的重要指标。

**数据来源**：

- 夜间时段（22:00–06:00）的行为分类序列
- 夜间 SCRATCH 帧占总夜间有效帧的比例
- 夜间睡眠中断次数（从 SLEEP 切换到 SCRATCH/MOVEMENT 的次数）

**子指标定义**：

```
night_scratch_ratio = (夜间 SCRATCH 帧数) / (夜间有效总帧数)

sleep_interruption_count = 夜间 [SLEEP → SCRATCH] 或 [SLEEP → MOVEMENT] 的状态跳转次数
```

**评分规则**：

| 子指标 | 权重 | 说明 |
|--------|------|------|
| 夜间抓挠比例 | 60%（满分12分） | 占夜间总时间比例越高，扣分越多 |
| 睡眠中断次数 | 40%（满分8分） | 与个体基线比较，Z-score 映射 |

**夜间抓挠比例评分表**：

| 夜间抓挠比例 | 分值（0–12） |
|-------------|-------------|
| ≤ 1% | 12（理想） |
| 1%–3% | 9 |
| 3%–6% | 6 |
| 6%–10% | 3 |
| > 10% | 0 |

**睡眠中断次数评分表**（基于 Z-score）：

| Z-score | 分值（0–8） |
|---------|------------|
| Z ≤ 0 | 8（好于或等于基线） |
| 0 < Z ≤ 1.0 | 5 |
| 1.0 < Z ≤ 2.0 | 2 |
| Z > 2.0 | 0 |

```
S3_score = night_scratch_score + sleep_interruption_score
```

**可行性评级**: ★★★ **HIGH**

> 夜间时段数据通常噪声较低（犬只活动减少），行为分类更准确。睡眠中断检测依赖行为状态跳转，技术实现简单可靠。主要风险是极少数犬只夜间活动规律异常（如夜班主人导致作息不规律）。

### S4 颈部体温（10分）

**评估目标**：颈部皮肤温度升高是局部炎症反应的代理指标，与过敏/皮炎严重程度存在相关性。

**数据来源**：

- 颈部温度传感器日均值 `neck_temp_daily_mean`
- 颈部温度传感器日最高值 `neck_temp_daily_max`
- 个体颈温基线（EWMA）
- 同期环境温度（用于去除环境影响）

**计算公式**：

```
neck_temp_adjusted = neck_temp_daily_mean - k × env_temp_daily_mean
（k 为颈温对环境温度的回归系数，个体化校准）

Z_S4 = (neck_temp_adjusted - baseline_neck_temp_mean) / baseline_neck_temp_std
S4_score = clamp(Z_score_to_points_S4(Z_S4), 0, 10)
```

**Z-score 到分数映射（满分10）**：

| Z-score 区间 | S4 分值（0–10） |
|-------------|----------------|
| Z ≤ 0 | 0（低于或等于基线，无异常） |
| 0 < Z ≤ 0.5 | 2 |
| 0.5 < Z ≤ 1.0 | 4 |
| 1.0 < Z ≤ 1.5 | 6 |
| 1.5 < Z ≤ 2.0 | 8 |
| Z > 2.0 | 10 |

> 注：S4 分值越高代表颈温偏离越大（炎症可能越重），与 S1/S2/S3 逻辑一致（高分=症状重）。

**可行性评级**: ★★ **MEDIUM**

> 颈部温度受多因素影响：环境温度、运动产热、毛发覆盖、传感器贴合度。个体化回归系数需要足够历史数据才能稳定，Phase 0–1 期间该维度置信度较低。建议在 Phase 0 期间仅记录，不纳入评分或降低权重。

---

### S5 追问树结果（15分）

**评估目标**：主人的直接观察往往能捕获传感器无法覆盖的信息（如腹部、耳道、眼周的抓挠，以及皮肤外观变化），追问树将主观观察结构化为 L0–L10 评级。

**追问树逻辑（分支示意）**：

```
Q1: 今天是否观察到犬只有抓挠/舔舐/蹭墙行为？
├── 否 → L0
└── 是 → Q2

Q2: 这些行为的频率如何？
├── 偶尔（每天 1-2 次，每次 < 30秒）→ Q3a
├── 频繁（明显注意到，每天多次）→ Q3b
└── 持续（几乎无法停止）→ Q3c

Q3a（偶尔）: 是否有皮肤变化（红、脱毛、结痂）？
├── 否 → L1
└── 是（轻微）→ L2

Q3b（频繁）: 是否影响犬只日常活动（进食/玩耍/睡眠）？
├── 否，皮肤基本正常 → L3
├── 轻微影响，皮肤有轻微变化 → L4
├── 明显影响，皮肤可见抓痕/红斑 → L5
└── 严重影响，皮肤有明显损伤/脱毛 → L6

Q3c（持续）: 是否需要主人干预才能停止？
├── 偶尔需要干预，皮肤有明显损伤 → L7
├── 经常需要干预，皮肤广泛损伤 → L8
├── 必须干预，皮肤溃疡/大面积脱毛 → L9
└── 无法通过干预停止 → L10
```

**L0–L10 对应描述**：

| 等级 | 主观描述 | 皮肤表现 |
|------|----------|----------|
| L0 | 无观察到的抓挠行为 | 皮肤正常 |
| L1 | 偶发、短暂，不引起注意 | 皮肤正常 |
| L2 | 偶发，主人开始注意到 | 皮肤轻微变化 |
| L3 | 每日可观察到，不困扰犬只 | 皮肤基本正常 |

### S6 环境修正（±5分）

**评估目标**：高温高湿环境会加剧皮肤瘙痒，如果环境因素可以解释部分抓挠行为，则调整最终评分（避免环境异常被错误地归因为病情恶化）。

**数据来源**：

- 环境温湿度传感器日均值
- 当日抓挠时间段与高温/高湿时间段的时间相关性分析

**计算逻辑**：

```
# 计算环境应激指数（Heat Stress Index，HSI）
THI = 0.8 × env_temp + env_humidity/100 × (env_temp - 14.4) + 46.4

# 对比当日 THI 与该犬只的历史 THI 基线
Z_THI = (THI_daily - baseline_THI_mean) / baseline_THI_std

# 计算抓挠行为与高THI时段的时间相关系数
scratch_env_correlation = pearson_r(scratch_events_per_hour, THI_per_hour)

# 环境修正分值计算
if Z_THI > 1.0 and scratch_env_correlation > 0.5:
    S6_score = -3 to -5   # 环境可解释部分症状，降低评分
elif Z_THI < -1.0:
    S6_score = +2 to +5   # 在低应激环境下仍有高频抓挠，可能病情更重，提高评分
else:
    S6_score = 0           # 环境正常，不修正
```

**S6 分值映射表**：

| 环境情况 | 与抓挠相关性 | S6 修正值 |
|----------|-------------|----------|
| 环境应激显著偏高（Z_THI > 2.0） | 高度相关（r > 0.7） | -5 |
| 环境应激明显偏高（1.0 < Z_THI ≤ 2.0） | 中度相关（0.5 < r ≤ 0.7） | -3 |
| 环境正常（\|Z_THI\| ≤ 1.0） | 任意 | 0 |
| 环境应激明显偏低（Z_THI ≤ -1.0） | — | +3 |
| 环境应激显著偏低（Z_THI ≤ -2.0） | — | +5 |

**可行性评级**: ★★ **MEDIUM**

> THI 指数需要在室内环境下验证其有效性（传感器安装在项圈上，可能不完全代表室内整体环境）。时间相关性分析需要逐小时数据对齐，计算复杂度适中。建议 Phase 1 期间此维度先设为0，积累足够数据后再启用。

## 8. 完整评分示例：旺旺

### 8.1 旺旺的背景信息

| 属性 | 信息 |
|------|------|
| 犬只名称 | 旺旺 |
| 品种 | 柴犬 |
| 年龄 | 3岁 |
| 项圈使用天数 | 第35天（Phase 3，稳定期） |
| 评估日期 | 2026-05-22（夏季，天气炎热） |
| 个体基线状态 | 基线已充分建立（Phase 3） |

### 8.2 当日原始数据摘要

| 指标 | 当日值 | 个体基线均值 | 个体基线标准差 | Z-score |
|------|--------|-------------|---------------|---------|
| 日 PEB 总数 | 18次 | 8次 | 4次 | **+2.50** |
| 日 W-PEB 总分 | 32.5 | 12.0 | 8.0 | **+2.56** |
| 夜间抓挠比例 | 7.8% | — | — | — |
| 夜间睡眠中断次数 | 6次 | 2次 | 1.5次 | **+2.67** |
| 颈部温度日均值（校正后） | +1.2°C偏离 | 0 | 0.5°C | **+2.40** |
| 环境 THI | 76.3 | 68.0 | 5.0 | **+1.66** |
| 抓挠-THI 时间相关系数 | r = 0.62 | — | — | — |

> 今日天气闷热，环境温湿度传感器显示环境应激明显偏高，抓挠时间段与高THI时段中度相关。

### 8.3 各维度评分计算

**S1 抓挠频次（满分25）**

```
Z_S1 = (18 - 8) / 4 = +2.50  →  Z > 2.0  →  S1 = 25分
```

**S2 抓挠强度与时长（满分25）**

```
W-PEB 构成：10次Light(×1.0) + 5次Medium(×1.5) + 3次Heavy(×2.5)
         = 10 + 7.5 + 7.5 = 25.0（此处示意，实际值为32.5）

Z_S2 = (32.5 - 12.0) / 8.0 = +2.56  →  Z > 2.0  →  S2 = 25分
```

**S3 夜间静息质量（满分20）**

```
夜间抓挠比例 = 7.8%  →  处于 6%-10% 区间  →  夜间抓挠分 = 3分

睡眠中断 Z-score = (6-2)/1.5 = +2.67  →  Z > 2.0  →  睡眠中断分 = 0分

S3 = 3 + 0 = 3分
```

**S4 颈部体温（满分10）**

```
Z_S4 = (颈温偏离 1.2°C) / 0.5 = +2.40  →  Z > 2.0  →  S4 = 10分
```

**S5 追问树结果（满分15）**

```
主人今日填写追问树：
  Q1: 是（明显抓挠行为）
  Q2: 频繁（每天多次）
  Q3b: 明显影响，皮肤可见抓痕/红斑
  → 追问树输出：L5

L5 → S5 = 8分
```

**S6 环境修正（±5分）**

```
Z_THI = (76.3 - 68.0) / 5.0 = +1.66  →  1.0 < Z_THI ≤ 2.0
scratch_env_correlation = 0.62  →  0.5 < r ≤ 0.7

→ S6 = -3分（环境应激偏高且与抓挠中度相关，适当降低评分）
```

| S2 抓挠强度与时长 | 25 | 25 |
