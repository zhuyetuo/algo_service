# 智能宠物项圈 · 算法模块介绍

---

## 我们在做什么

项圈内置 6 轴运动传感器和温度传感器，以 50Hz 频率持续采集狗狗颈部的运动数据。算法的目标是把这些原始数据加工成一个可读懂的健康状态评估结果，供 App 展示给主人。

**核心价值：替代主人的记忆。**

主人可能只记得"今天好像挠了几次"，但项圈记得是 17 次、最长的一次挠了 43 秒、凌晨两点挠醒了三次。

---

## 输出结果：L0–L10 健康等级

最终产出是一个 **L0 到 L10 的瘙痒健康等级**，与临床 PVAS（瘙痒视觉模拟量表）对标：

| 等级 | 描述 | App 建议 |
|-----|------|---------|
| L0–L2 | 正常 / 极轻微 | 继续观察 |
| L3–L5 | 轻度 / 轻中度 | 关注趋势，建议填写问卷 |
| L6–L7 | 中度 | 建议本周预约兽医 |
| L8–L9 | 重度 | 建议尽快就医 |
| L10 | 极重度 | 建议立即急诊 |

评分由五个维度组成：

- **S1 抓挠频次**（25分）：今天共发生多少次抓挠行为
- **S2 抓挠强度与时长**（25分）：每次抓挠的用力程度和持续时间
- **S3 睡眠质量**（20分）：夜间是否被瘙痒打断
- **S4 颈部体温**（10分）：有无局部发热的异常趋势
- **S5 主人问卷**（15分）：皮肤有无发红、脱毛、结痂（需主人填写）

---

## 判断逻辑：和自己比，不和别人比

系统不使用固定阈值，而是为**每只狗建立独立的个体基线**，持续学习它自己的正常状态。

> 有些狗天生就爱挠，系统会把这个较高的基线当作它的正常。只有当"今天的行为比它自己以往明显偏高"时，才判定为异常。

这样设计的原因是：不同品种、年龄、个体差异巨大，统一阈值会造成大量误报或漏报。

## 当前能做到什么

| 能力 | 状态 |
|-----|------|
| 抓挠次数、强度、时长的自动识别 | ✅ 可靠检测 |
| 夜间睡眠质量评估 | ✅ 可靠检测 |
| 颈部体温趋势监测 | ✅ 可靠检测 |
| 个体基线学习与动态更新 | ✅ 已实现 |
| 舔爪、磨屁股行为识别 | ⚠️ 当前版本覆盖率低 |
| 皮肤外观评估 | ❌ 需主人拍照，项圈无摄像头 |
| L9–L10 极重度判断 | ❌ 此阶段需兽医现场评估 |

> **L9–L10 说明**：极重度阶段狗狗可能已精力耗尽、行为反而减少，传感器数据会失真。这个区间的判断必须依赖兽医现场评估，算法只做辅助参考。

---

## 现在到哪里了

**第一阶段（当前）**：机器学习方案，专注抓挠识别二分类，准确率约 85%。规则方法作为兜底并行运行。

**第二阶段（数据积累后）**：引入 XGBoost 学习评分映射，目标准确率 88–90%。同时扩展行为识别到走、跑、跳、睡眠细分。关键瓶颈是**兽医标注的真实 L 级病例数据**。

**第三阶段（远期）**：深度学习方案，目标准确率 90–94%，支持猫咪扩展。

## 各方向的配合需求

**兽医**
- 帮助校验算法给出的 L 级是否与临床判断吻合
- 就诊犬只如有佩戴项圈，协助记录兽医评估的 L 级结果（这是提升模型的核心数据）

**产品**
- 主人问卷占评分的 15%，交互设计上希望尽量降低填写门槛
- 分级推送通知的时机和文案，需要产品侧确认用户体验边界

**硬件测试**
- 传感器数据质量验证、佩戴状态检测逻辑、异常场景复现
- 详细测试规范文档会后单独对齐
