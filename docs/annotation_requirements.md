# 智能宠物项圈数据标注需求文档

## 一、传感器说明

项圈内置以下传感器，标注人员需了解各传感器采集的内容：

* 加速度计（3轴）：X / Y / Z 方向的加速度，反映宠物身体的运动和冲击
* 陀螺仪（3轴）：X / Y / Z 方向的旋转角速度，反映宠物身体的转动和摆动
* 环境温度：周围空气温度（°C），记录宠物所处环境的温度
* 环境湿度：周围空气湿度（%RH），记录宠物所处环境的湿度
* 脖颈温度：皮肤接触温度（°C），反映宠物体温变化

项圈佩戴在宠物颈部，所有传感器数据均为颈部位置采集。

---

## 二、文件结构说明

每次采集由以下文件组成，通过 session_id 和 pet_id 相互关联：

* `PET_INFO.csv`：宠物档案，所有宠物信息汇总，一次性填写
* `SESSION_INDEX.csv`：数据索引，每组采集数据一条记录
* `VID_日期_宠物编号_序号.mp4`：视频文件，标注人员看这个打标签
* `IMU_日期_宠物编号_序号.csv`：6轴IMU原始数据，50Hz
* `ENV_日期_宠物编号_序号.csv`：环境温湿度与脖颈温度，1Hz
* `ANN_日期_宠物编号_序号.csv`：标注结果文件，供应商交付
* `WEAR_日期_宠物编号_序号.csv`：佩戴状态标注文件（新增，由算法团队标注，非外包）
* `PVAS_日期_宠物编号_序号.csv`：PVAS等级标注文件（新增，由兽医标注，第二阶段使用）

## 三、数据格式示例

### PET_INFO.csv（宠物档案）

物种必须填写，其余字段不知道时填 `未知`。

体型：小型（≤10kg）/ 中型（10-25kg）/ 大型（≥25kg）/ 未知  
毛发：短毛 / 长毛 / 未知

字段说明：pet_id / 物种 / 品种 / 年龄(月) / 性别 / 绝育 / 体型 / 毛发

```csv
pet_id,物种,品种,年龄(月),性别,绝育,体型,毛发
DOG_042,狗,金毛寻回犬,36,公,是,大型,长毛
CAT_018,猫,未知,未知,母,未知,未知,短毛
DOG_088,狗,未知,未知,未知,未知,中型,未知
```

### SESSION_INDEX.csv（数据索引）

字段说明：session_id / pet_id / 视频文件名 / IMU文件名 / ENV文件名

```csv
session_id,pet_id,视频文件名,IMU文件名,ENV文件名
S_20260501_DOG042_001,DOG_042,VID_20260501_DOG042_001.mp4,IMU_20260501_DOG042_001.csv,ENV_20260501_DOG042_001.csv
```

### IMU 数据文件（50Hz，每20ms一条）

字段说明：timestamp / acc_x / acc_y / acc_z / gyro_x / gyro_y / gyro_z  
acc 单位：g；gyro 单位：°/s

```csv
timestamp,acc_x,acc_y,acc_z,gyro_x,gyro_y,gyro_z
2026-05-01 08:00:00.000,0.12,-0.03,0.98,0.01,0.02,-0.01
2026-05-01 08:00:00.020,0.11,-0.02,0.97,0.01,0.01,-0.01
```

### ENV 数据文件（1Hz，每1s一条）

字段说明：timestamp / env_temp / env_humidity / neck_temp

```csv
timestamp,env_temp,env_humidity,neck_temp
2026-05-01 08:00:00.000,24.5,55.2,38.1
2026-05-01 08:00:01.000,24.5,55.3,38.1
```

### ANN 标注文件

字段说明：session_id / 开始时间 / 结束时间 / 行为标签 / 标注员ID / 备注

> 注意：行为标注只在 WORN_NORMAL 时段内进行，WORN_LOOSE 和 NOT_WORN 时段标 UNKNOWN。

```csv
session_id,开始时间,结束时间,行为标签,标注员ID,备注
S_20260501_DOG042_001,2026-05-01 08:00:00.000,2026-05-01 08:30:00.000,SLEEP,ANN_003,
S_20260501_DOG042_001,2026-05-01 08:30:00.000,2026-05-01 08:32:00.000,SCRATCH,ANN_003,
S_20260501_DOG042_001,2026-05-01 08:32:00.000,2026-05-01 08:40:00.000,MOVE,ANN_003,
```

### WEAR 佩戴状态文件（由算法团队内部标注）

字段说明：session_id / 开始时间 / 结束时间 / 佩戴状态 / 备注

**佩戴状态枚举：**

| 状态值 | 含义 |
|---|---|
| WORN_NORMAL | 正常佩戴，项圈贴紧皮肤，传感器数据可信 |
| WORN_LOOSE | 项圈松动或移位，数据可信度低 |
| NOT_WORN | 未佩戴（放在桌上、充电中等） |

**判断依据（内部使用）：**

* NOT_WORN：加速度长时间静止 + 脖颈温度接近环境温度（差值 < 1°C）
* WORN_LOOSE：重力向量方差持续偏大，项圈晃动明显
* WORN_NORMAL：其余情况

```csv
session_id,开始时间,结束时间,佩戴状态,备注
S_20260501_DOG042_001,2026-05-01 08:00:00.000,2026-05-01 09:30:00.000,WORN_NORMAL,
S_20260501_DOG042_001,2026-05-01 09:30:00.000,2026-05-01 10:00:00.000,NOT_WORN,主人取下充电
S_20260501_DOG042_001,2026-05-01 10:00:00.000,2026-05-01 10:05:00.000,WORN_LOOSE,重新佩戴后调整中
S_20260501_DOG042_001,2026-05-01 10:05:00.000,2026-05-01 12:00:00.000,WORN_NORMAL,
```

### PVAS 等级标注文件（由兽医标注，第二阶段使用）

字段说明：session_id / 评估日期 / PVAS等级 / 行为次数 / 作息影响 / 皮肤外观 / 标注兽医 / 备注

* PVAS等级：L0 / L1 / L2 / L3 / L4 / L5 / L6 / L7 / L8 / L9 / L10
* 行为次数：24小时内观察到的瘙痒相关行为总次数（兽医/主人填写）
* 作息影响：无影响 / 轻微影响 / 明显影响 / 严重影响
* 皮肤外观：正常 / 轻微变化 / 明显异常 / 严重损伤

```csv
session_id,评估日期,PVAS等级,行为次数,作息影响,皮肤外观,标注兽医,备注
S_20260501_DOG042_001,2026-05-01,L4,10,轻微影响,轻微变化,VET_001,耳朵周围轻微发红
```

## 四、标注任务说明

标注人员需要观看宠物视频，对视频中宠物的行为打上对应标签。

标注时按行为实际发生的时间段标注，记录每段行为的开始时间和结束时间。时间精度要求到毫秒，格式为 `YYYY-MM-DD HH:MM:SS.mmm`。

相邻两段的结束时间与开始时间必须完全一致，不能有空隙也不能重叠。

---

## 五、行为标签

### 第一阶段标签

* **MOVE（运动）**：宠物有明显的身体移动，包括行走、跑步、跳跃、玩耍等
* **SCRATCH（抓挠）**：宠物任何与瘙痒相关的行为，包括挠、蹭、啃咬、甩头等
* **SLEEP（睡觉/静止）**：宠物躺着、趴着或坐着，身体几乎不动
* **UNKNOWN（无法判断）**：视频不清晰、宠物被遮挡，或行为不符合以上任何一类

### 第二阶段标签

第二阶段在第一阶段基础上对 MOVE、SCRATCH 和 SLEEP 进行细分，标注要求更高。

#### MOVE 细分：

* **MOVE_WALK（行走）**：缓慢移动，四肢交替迈步，节奏平稳
* **MOVE_TROT（小跑）**：中速跑动，节奏规律，步幅适中
* **MOVE_RUN（奔跑）**：快速跑动，步幅大，明显用力
* **MOVE_JUMP（跳跃）**：腾空跳起，包括上下台阶的跳跃
* **MOVE_PLAY（玩耍）**：追逐、扑咬玩具或其他动物，动作不规律

#### SCRATCH 细分：

按身体部位分为前/中/后/四肢四个区域。

以下识别难度评估（✅⚠️❌）为算法工程师基于IMU信号特征的初步预判：
* ✅ 信号特征明显，预计较容易识别
* ⚠️ 信号与其他行为类似，可能导致误识别
* ❌ 信号变化太弱，该类别可能难以有效识别

**看不清楚时，一律标 SCRATCH，不得猜测。**

**前（头/脸/耳/颈）：**
* SCRATCH_FRONT_PAW（后爪挠头/脸/耳，✅）
* SCRATCH_FRONT_SHAKE（甩头，⚠️）
* SCRATCH_FRONT_RUB（蹭脸，⚠️）
* SCRATCH_FRONT_LICK（舔爪子后擦脸，❌）

**中（胸/腹/背/侧腹）：**
* SCRATCH_MID_PAW（后爪挠腹部/侧腹，✅）
* SCRATCH_MID_BITE_BELLY（啃咬腹部/侧腹，⚠️）
* SCRATCH_MID_BITE_BACK（啃咬背部，❌）
* SCRATCH_MID_RUB_BACK（蹭背部，⚠️）
* SCRATCH_MID_RUB_BELLY（蹭胸部/腹部，⚠️）
* SCRATCH_MID_LICK_BELLY（舔腹部，❌）
* SCRATCH_MID_LICK_SIDE（舔侧腹，❌）

**后（屁股/尾根）：**
* SCRATCH_REAR_BITE（啃咬尾根/屁股，⚠️）
* SCRATCH_REAR_LICK（舔尾根/屁股，❌）
* SCRATCH_REAR_SCOOT（屁股蹭地，✅）
* SCRATCH_REAR_RUB（蹭屁股，⚠️）

**四肢（前腿/后腿/爪子）：**
* SCRATCH_LIMB_BITE（啃咬四肢，⚠️）
* SCRATCH_LIMB_LICK（舔爪子/四肢，❌）
* SCRATCH_LIMB_PAW（后爪挠后腿，✅）
* SCRATCH_LIMB_RUB（蹭腿，❌）

#### SLEEP 细分（第二阶段新增）：

* **SLEEP_MAIN（主睡眠）**：当天最长的连续睡眠段，通常为夜间主睡眠。  
  判断规则：连续 SLEEP 时长 ≥ 2小时，且为当天最长连续睡眠段
* **SLEEP_NAP（小睡）**：主睡眠以外的短暂休息，单段时长 < 2小时
* **SLEEP_REST（静止休息）**：清醒状态下的趴着/坐着静止，无睡眠迹象

> 注意：同一只狗同一天只有一段 SLEEP_MAIN，其余睡眠均为 SLEEP_NAP。  
> 有些狗作息颠倒（白天睡、夜晚活跃），以实际最长连续段为准，不以时间段判断。

## 六、标注质量要求

1. 不确定时标 UNKNOWN，不要强行归类
2. 视频看不清、宠物被遮挡超过 50% 的片段，一律标 UNKNOWN
3. **双人独立标注要求**  
   第二阶段所有样本需两名标注员独立标注，一致性要求：
   * 行为类别一致率 ≥ 90%（同一时间段两人标签相同）
   * 时间边界偏差 ≤ 500ms
   * 一致率低于 90% 的片段，提交第三人仲裁
   * 一致率持续低于 85% 的标注员需重新培训

4. **颈温异常备注要求**  
   当 ENV 文件中脖颈温度出现以下情况时，标注员需在备注栏注明：
   * 颈温比前10分钟均值高出 1°C 以上：备注"颈温升高_[原因]"  
     原因选项：运动后 / 疑似炎症 / 环境温度高 / 未知
   * 颈温低于环境温度 1°C 以内：备注"疑似松动"

## 七、常见问题

**Q：宠物同时在抓挠又在走动，选哪个？**  
选最明显的主要行为。如果真的各占一半，标 UNKNOWN 并在备注说明。

**Q：宠物睡觉时偶尔动了一下，还是 SLEEP 吗？**  
是的，只要整体是躺着休息状态，标 SLEEP。

**Q：SCRATCH 细分看不清楚部位或方式怎么办？**  
直接标 SCRATCH，不要猜。

**Q：小狗和成年狗的标准一样吗？**  
一样，行为标签不区分年龄。

**Q：项圈明显松了，视频里能看到项圈晃动，还要继续标注行为吗？**  
标行为标签时正常标，同时在备注写"项圈松动"。佩戴状态由算法团队单独处理，不影响行为标注。

**Q：SLEEP_MAIN 怎么判断，采集时段内没有夜间睡眠怎么办？**  
以当次采集视频中最长的连续 SLEEP 段为 SLEEP_MAIN。如果最长的 SLEEP 段不足2小时，全部标 SLEEP_NAP。

**Q：狗狗刚佩戴上项圈时一直在抓挠项圈，算 SCRATCH 吗？**  
算，标 SCRATCH_FRONT_PAW 或对应部位，备注"适应项圈"。这类数据同样有价值。

## 八、数据采集需求

### 第一阶段 · ML · 犬类二分类（当前）

目标：识别有没有抓挠

* 采集方式：连续录制，单次建议 1-4 小时，不人工引导
* SCRATCH 有效时长：≥ 2小时
* MOVE 有效时长：≥ 2小时
* SLEEP 有效时长：≥ 2小时
* 个体数量：≥ 50条狗
* 体型覆盖：小型犬（≤10kg）/ 中型犬（10-25kg）/ 大型犬（≥25kg）各至少15条
* 毛发覆盖：短毛 / 长毛各占一半

### 第二阶段 · DL · 犬类细分（1-2年内）

目标：MOVE细分 + SCRATCH细分 + SLEEP细分

* 采集方式：连续录制，单次建议 1-4 小时，不人工引导
* MOVE 每个子类各 ≥ 3小时
* SCRATCH 每个子类各 ≥ 2小时（共18个子类）
* SLEEP 有效时长：≥ 5小时
* 个体数量：≥ 150条狗
* 体型覆盖：小型犬 / 中型犬 / 大型犬各至少50条
* 毛发覆盖：短毛 / 长毛各占一半
* 总采集时长估算：约 30-50 小时原始视频

### 第二阶段补充 · PVAS等级标注（配合第二阶段，由兽医完成）

目标：为 XGBoost 评分模型提供训练标签

* 标注方式：兽医现场评估 + 主人问卷结合
* 每个等级目标样本数：
  * L0–L2（正常/极轻）：各 ≥ 30 例（量大，追问树弱标签可补充）
  * L3–L5（轻中度）：各 ≥ 50 例（重点收集，临床最常见）
  * L6–L8（中重度）：各 ≥ 30 例
  * L9–L10（极重度）：各 ≥ 10 例（极端案例，尽力收集）
* 收集渠道：
  1. App 内持续异常推送后用户就医，App 引导填写兽医结果
  2. 合作宠物医院，就诊犬只佩戴项圈采集 24 小时数据
  3. 高等级（L6+）案例优先，可联系皮肤病专科诊所
* 时间要求：兽医评估与项圈数据时间差 ≤ 24 小时

### 第三阶段 · DL · 加入猫（2-3年内）

目标：猫的行为识别

* SCRATCH 有效时长：≥ 2小时
* MOVE 有效时长：≥ 3小时
* SLEEP 有效时长：≥ 3小时
* 个体数量：≥ 100只猫
* 毛发覆盖：短毛 / 长毛各占一半
