# 犬只瘙痒评估：智能项圈 + 问卷联合评估方案

**面向对象：产品经理 / 业务团队**
**版本：v1.0 | 2026-05-25**

---

## 一、我们在评估什么？

PVAS（瘙痒视觉模拟量表）由三个维度组成，总分加权计算：

| 维度 | 权重 | 谁来负责 |
|------|------|----------|
| 行为次数（抓/啃/舔/蹬/甩头/磨屁股的次数） | 40% | **项圈直接检测** |
| 作息影响（睡眠、进食、玩耍是否受干扰） | 30% | **项圈检测 + 问卷辅助** |
| 皮肤外观（发红、脱毛、结痂、破皮） | 30% | **问卷/主人拍照** |

这三条腿缺一不可。项圈是最强的那条腿——它 24 小时不间断地看着狗狗，不靠主人记忆，不靠主观感受。但皮肤长什么样，目前只能靠主人反馈。所以**项圈 + 问卷联合使用，才是完整评估**。

## 二、项圈能检测什么？

### 高置信度检测（项圈可直接检测）

| 行为 | 原理 |
|------|------|
| 爪挠颈部 | 颈部高频振动，信号强且独特 |
| 甩头 | 陀螺仪捕捉快速旋转，极易识别 |
| 睡眠中断 | 睡眠状态被打断，可精确计时 |
| 抓挠频率与强度 | 直接计数，可量化 |
| 作息规律异常 | 睡眠/活动分布整体变化，可追踪 |

### 中等置信度检测（需配合问卷）

| 行为 | 说明 |
|------|------|
| 啃咬颈部附近 | 项圈有感应，但与抓挠信号相似，需结合问卷确认 |
| 蹬腿挠身 | 身体晃动项圈可部分感知，但信号较弱 |
| 进食减少 | 通过活动规律间接推断，需问卷确认 |

### 当前版本暂不覆盖

| 行为 | 原因 |
|------|------|
| 舔爪 / 舔身体 | 狗狗静止时舔，项圈几乎感知不到 |
| 磨屁股（肛门腺问题） | 动作在身体后部，项圈无信号 |
| 皮肤外观 | 需要视觉观察，项圈无摄像头 |

## 三、L0–L10 联合评估能力表

| PVAS 等级 | 描述 | 项圈检测 | 问卷作用 | 产品置信度 | App 推荐动作 |
|-----------|------|----------|----------|------------|--------------|
| **L0** 正常 | 24h 无任何瘙痒行为 | 🟢 行为计数=0，睡眠完整 | — | **高** | 显示"一切正常，继续观察" |
| **L1** 极微痒 | 1-2次，极短，完全不影响作息 | 🟢 偶发信号，强度极低 | — | **高** | "偶发轻微瘙痒，属正常范围" |
| **L2** 非常轻度 | 3-5次，睡眠正常 | 🟢 可计数，睡眠无中断 | 🟡 确认皮肤无异常 | **高** | "轻微瘙痒信号，建议填写皮肤问卷" |
| **L3** 轻度偏轻 | 6-8次，多为舔爪/蹭地 | 🟡 部分行为项圈漏检 | 🟡 问卷补充舔爪/蹭地信息 | **中** | "检测到轻度瘙痒迹象，请完成问卷" |
| **L4** 轻度 | 9-12次，分心时不痒，夜间偶尔 | 🟢 抓挠频率升高，🟡夜间中断偶发 | 🟡 确认进食/玩耍是否受影响 | **中-高** | "轻度瘙痒，建议记录持续情况，关注7天趋势" |
| **L5** 轻中度 | 13-16次，开始成阵，夜间1-2次 | 🟢 阵发模式可识别，夜醒可计 | 🟡 皮肤问卷（是否有小片脱毛） | **中** | "中度瘙痒信号，建议本周就医评估" |
| **L6** 中度 | 17-22次，玩耍进食频繁被打断 | 🟢 频繁抓挠，作息明显异常 | 🟡 皮肤问卷（红斑/丘疹） | **中** | "明显瘙痒，建议尽快预约兽医" |
| **L7** 中度偏重 | 23-30次，反复啃咬同一部位，情绪烦躁 | 🟢 高频高强度信号，睡眠严重碎片化 | 🟡 皮肤问卷（结痂/增厚） | **中** | "严重瘙痒，请在3天内就医" |
| **L8** 重度 | >30次，阵发持续1-5分钟 | 🟢 持续高强度信号，夜间频繁中断 | 🟡 皮肤问卷（糜烂/色素沉着）| **中-低** | "重度瘙痒，请今天就医" |
| **L9** 极重度 | 几乎不停，无法正常睡觉进食 | 🟡 极端情况下行为反而减少（力竭） | 🔴 皮肤状况问卷关键 | **低** | "极度异常信号，请立即就医" |
| **L10** 极致重度 | 持续无法中断，需物理约束 | 🔴 此阶段狗狗可能已无力持续 | 🔴 需兽医现场评估 | **低** | "紧急：请立即前往急诊" |

> **重要说明**：L9-L10 属于急诊级别，此时皮肤通常已严重破损。项圈信号在这个阶段反而可能因为狗狗精力耗尽而减弱，问卷和兽医评估是决定性依据。

## 四、整体覆盖率评估

| 评估维度 | 权重 | 项圈覆盖 | 问卷覆盖 | 合计覆盖 |
|----------|------|----------|----------|----------|
| 行为次数 | 40% | ~70%（漏检舔舐/磨屁股） | +15%（问卷补充） | ~85% |
| 作息影响 | 30% | ~80%（睡眠最强，进食弱） | +15%（问卷补充） | ~95% |
| 皮肤外观 | 30% | 0%（无摄像头） | ~80%（问卷+拍照） | ~80% |
| **综合** | **100%** | **~45%** | **+40%** | **~85%** |

**结论**：单项圈覆盖约 45% 的 PVAS 信息量；项圈 + 完整问卷可达到约 85% 的评估置信度。最后 15% 主要是皮肤外观的细节（如破溃程度、继发感染），需要兽医现场评估。

## 五、评分计算公式

### 5.1 总分结构

总分由六个维度相加，满分 100 分，对应 L0–L10：

```
总分 = S1 + S2 + S3 + S4 + S5 + S6

S1  抓挠频次        满分 25 分
S2  抓挠强度与时长  满分 25 分
S3  主睡眠期质量    满分 20 分
S4  颈部体温        满分 10 分
S5  问卷结果        满分 15 分
S6  环境修正        ±5 分

总分 0–9   → L0    总分 50–59 → L5
总分 10–19 → L1    总分 60–69 → L6
总分 20–29 → L2    总分 70–79 → L7
总分 30–39 → L3    总分 80–89 → L8
总分 40–49 → L4    总分 90–99 → L9   总分 100 → L10
```

### 5.2 核心概念：个体基线与 Z-score

**什么是个体基线？**
系统记录这只狗过去数周的日常抓挠次数，计算出它"正常情况下"平均每天挠多少次，以及波动范围有多大。这个正常水平叫做**个体基线**。

**什么是 Z-score？**
Z-score 衡量今天的表现偏离这只狗自己正常水平多少倍。

```
Z-score = (今日数值 − 个体日常均值) ÷ 个体日常波动幅度

Z = 0    → 和平时一样
Z = 1    → 比平时高出 1 个波动幅度（轻度偏高）
Z = 2    → 比平时高出 2 个波动幅度（明显偏高）
Z > 3    → 显著异常
```

**为什么用 Z-score 而不用绝对次数？**
不同狗的正常抓挠次数差异很大。一只活跃的边牧每天抓 8 次可能完全正常，但一只安静的法斗每天抓 8 次可能已经异常。Z-score 消除了这种个体差异。

### 5.3 各维度计算规则

**S1 抓挠频次（满分 25 分）**

```
计算今日 PEB 数（有效抓挠事件数）
→ PEB 规则：持续 ≥3 秒、与上次间隔 ≥30 秒，才算一次独立事件
→ 计算 Z-score
→ 映射到分数：

Z ≤ 0.5   →  0–8 分（正常范围）
Z = 1.0   →  13 分
Z = 1.5   →  18 分
Z = 2.0   →  22 分
Z > 2.0   →  25 分
```

**S2 抓挠强度与时长（满分 25 分）**

```
计算 W-PEB（加权抓挠负担）：
  W-PEB = 轻度次数 × 1.0 + 中度次数 × 1.5 + 重度次数 × 2.5
→ 强度由项圈加速度信号大小自动判断
→ 与个体基线比较，计算 Z-score，映射规则同 S1
```

**S3 主睡眠期质量（满分 20 分）**

```
主睡眠窗口 = 当天最长连续睡眠时段（系统自动识别，不固定 22:00–06:00）

子指标一：睡眠期抓挠比例（满分 12 分）
  比例 ≤1%   → 12 分
  比例 1–3%  →  9 分
  比例 3–6%  →  6 分
  比例 6–10% →  3 分
  比例 >10%  →  0 分

子指标二：睡眠中断次数 Z-score（满分 8 分）
  Z ≤ 0      →  8 分（好于或等于平时）
  Z = 0–1    →  5 分
  Z = 1–2    →  2 分
  Z > 2      →  0 分

S3 = 子指标一 + 子指标二
```

**S4 颈部体温（满分 10 分）**

```
去除环境温度影响后，与个体颈温基线比较：
  偏差 < 0.5°C  →  0 分（正常）
  偏差 0.5–1.0° →  4 分
  偏差 1.0–1.5° →  7 分
  偏差 > 1.5°C  → 10 分
```

**S5 问卷结果（满分 15 分）**

```
主人完成追问树后得出 L0–L10，映射到分数：
  L0 → 0 分     L6 → 9 分
  L1 → 1 分     L7 → 11 分
  L2 → 2 分     L8 → 12 分
  L3 → 4 分     L9 → 14 分
  L4 → 6 分     L10 → 15 分
  L5 → 7 分

问卷未填写时，S5 = 0，同时输出置信度降级提示。
```

**S6 环境修正（±5 分）**

```
分析当天抓挠时段与温湿度的相关性：
  高温高湿（>28°C，>70%）且抓挠集中在高温时段 → −5 分（环境驱动，下调）
  高温高湿但抓挠时间与温度无关              →  0 分
  温湿度正常                                →  0 分
  低温低湿仍大量抓挠                        → +3 分（排除环境，上调）
```

## 六、使用场景示例

### 场景一：正常狗狗，主人担心过度

**狗狗情况**：边牧小黑，2 岁，主人感觉它最近"老是挠"，来检测。

**原始数据**：
- 今日 PEB 数：5 次，个体基线均值 4.2 次，基线标准差 1.1 次
- W-PEB：5.5（全部轻度），基线 W-PEB 均值 4.5，标准差 1.2
- 主睡眠期（23:10–07:20）：抓挠占比 0.3%，睡眠中断 0 次（基线中断均值 0.5 次）
- 颈温偏差：+0.2°C
- 问卷：主人未填写
- 环境：温度 22°C，湿度 55%

**计算过程**：
```
S1：Z = (5 − 4.2) ÷ 1.1 = 0.73  →  13 分
S2：Z = (5.5 − 4.5) ÷ 1.2 = 0.83 →  13 分
S3：抓挠占比 0.3% → 12 分；中断 Z = (0−0.5)÷0.8 = −0.6 → 8 分；S3 = 20 分
S4：偏差 0.2°C → 0 分
S5：问卷未填 → 0 分（置信度降级）
S6：环境正常 → 0 分

总分 = 13 + 13 + 20 + 0 + 0 + 0 = 46 分 → L4
```

> ⚠️ 注意：S5=0 是因为主人没填问卷，实际如果填了且反馈"皮肤正常、影响不大"，S5 约得 1–2 分，总分仍在 L1–L2 区间。建议引导主人填写问卷后重新评估。

**App 显示**：项圈评估 L4（因问卷缺失置信度偏低），趋势稳定，30 天内无上升。

**推荐动作**：请完成皮肤问卷以提高评估准确性；填写后预计结果为 L1–L2 正常范围。

---

### 场景二：轻度季节性过敏

**狗狗情况**：金毛旺旺，5 岁，每年春天会有轻度过敏史，已佩戴项圈 45 天。

**原始数据**：
- 今日 PEB 数：11 次，个体基线均值 3.2 次，基线标准差 1.4 次
- W-PEB：16.5（轻度 6 次 + 中度 5 次），基线 W-PEB 均值 4.1，标准差 1.5
- 主睡眠期（22:40–06:50）：抓挠占比 4.2%，睡眠中断 2 次（基线中断均值 0.3 次，标准差 0.6）
- 颈温偏差：+0.8°C（运动结束 3 小时后，非运动产热）
- 问卷：主人填写"耳朵周围轻微发红，无脱毛"→ 追问树输出 L3
- 环境：温度 26°C，湿度 65%，与抓挠时间相关性弱

**计算过程**：
```
S1：Z = (11 − 3.2) ÷ 1.4 = 5.57  →  25 分（Z > 2，满分）
S2：Z = (16.5 − 4.1) ÷ 1.5 = 8.27 → 25 分（Z > 2，满分）
S3：抓挠占比 4.2% → 6 分
    中断 Z = (2 − 0.3) ÷ 0.6 = 2.83 → 0 分
    S3 = 6 + 0 = 6 分
S4：偏差 +0.8°C → 4 分
S5：问卷 L3 → 4 分
S6：环境相关性弱 → 0 分

总分 = 25 + 25 + 6 + 4 + 4 + 0 = 64 分 → L6
```

**App 显示**：PVAS L6，中度瘙痒，行为频次和强度均显著高于个体基线（Z>5），睡眠受影响，皮肤轻度异常。

**推荐动作**：建议尽快预约兽医，考虑季节性过敏排查。提供近 7 天趋势图供兽医参考。

### 场景三：严重皮肤病，行为与症状双重升高

**狗狗情况**：法斗豆豆，6 岁，有特应性皮炎史，已佩戴项圈 60 天。

**原始数据**：
- 今日 PEB 数：26 次，个体基线均值 5.1 次，基线标准差 1.8 次
- W-PEB：52.0（轻度 8 次 + 中度 10 次 + 重度 8 次），基线 W-PEB 均值 6.2，标准差 2.1
- 主睡眠期（23:00–07:00）：抓挠占比 18%，睡眠中断 7 次（基线 0.4 次，标准差 0.7）
- 颈温偏差：+1.3°C（静息状态下持续偏高）
- 问卷：主人填写"腹部有红斑和结痂，部分区域脱毛"→ 追问树输出 L7
- 环境：温度 24°C，湿度 58%，正常范围

**计算过程**：
```
S1：Z = (26 − 5.1) ÷ 1.8 = 11.6  →  25 分（满分）
S2：Z = (52.0 − 6.2) ÷ 2.1 = 21.8 → 25 分（满分）
S3：抓挠占比 18% → 0 分
    中断 Z = (7 − 0.4) ÷ 0.7 = 9.4 → 0 分
    S3 = 0 + 0 = 0 分
S4：偏差 +1.3°C 静息状态 → 7 分
S5：问卷 L7 → 11 分
S6：环境正常 → 0 分

总分 = 25 + 25 + 0 + 7 + 11 + 0 = 68 分 → L6
```

> 注：S3=0 反映睡眠质量已严重崩溃——抓挠占据了大量本该是睡眠的时间，这本身就是重症信号。总分 L6 是项圈+问卷联合的结果，若问卷未填则为 L5，低估实际病情。

**App 显示**：PVAS L6（中重度），连续 5 天持续上升，已触发"持续异常模式"，基线冻结。

**推荐动作**：请在 24 小时内就医，附带近 7 天趋势报告（抓挠频次、强度、睡眠中断全部图表）。

### 场景四：主要靠舔舐的狗狗（项圈局限性体现）

**狗狗情况**：比熊，4 岁，主人观察到它频繁舔爪子，但项圈数据"看起来正常"。已佩戴项圈 35 天。

**原始数据**：
- 今日 PEB 数：2 次（项圈仅捕捉到少量颈部抓挠），基线均值 1.8 次，标准差 0.9
- W-PEB：2.0，基线 2.1，标准差 0.8
- 主睡眠期：抓挠占比 0.5%，中断 1 次（基线 0.6 次）
- 颈温偏差：+0.3°C
- 问卷：主人填写"舔爪非常频繁，每天超过 10 次，爪子周围轻微发红"→ 追问树输出 L4
- 环境：正常

**计算过程（项圈单独）**：
```
S1：Z = (2 − 1.8) ÷ 0.9 = 0.22  →  8 分
S2：Z = (2.0 − 2.1) ÷ 0.8 = −0.1 → 8 分
S3：占比 0.5% → 12 分；中断 Z = 0.5 → 5 分；S3 = 17 分
S4：0 分
S5：问卷未填假设 → 0 分
S6：0 分
项圈单独总分 = 8 + 8 + 17 + 0 + 0 + 0 = 33 分 → L3
```

**加入问卷后**：
```
S5：问卷 L4 → 6 分
总分 = 33 + 6 = 39 分 → L3（接近 L4 边界）
```

> ⚠️ 这是项圈已知盲区：舔舐行为发生时狗狗基本静止，项圈感知不到。项圈给出 L3，真实 PVAS 应为 L4–L5。App 需明确提示：**"检测到问卷与项圈数据存在差异，舔舐行为为项圈检测盲区，本次评估以问卷为主要依据。"**

**App 显示**：综合评估 L3–L4（问卷驱动），附加提示"该犬只属于舔舐型瘙痒，项圈数据参考价值有限，请优先依据问卷结果"。

**推荐动作**：建议本周就医。提醒主人：小型犬舔爪型瘙痒是项圈的已知盲区，坚持每日填写问卷比项圈数据更重要。

**短期可行方案**：在 App 中引导主人每周定期拍 1-2 张皮肤照片并上传，配合问卷评分，可以在不增加硬件的前提下显著提升皮肤维度的覆盖率。

---

## 八、给产品团队的关键结论

1. **项圈是评估的核心优势**：24h 客观行为数据，不依赖主人记忆，在 L0-L8 区间表现良好。

2. **问卷是必要补充，不是可选项**：皮肤外观占 30% 权重，不填问卷评估准确性大幅下降。需要在 UX 上强制引导用户完成问卷。

3. **舔舐盲区需要在 UX 上明确提示**：在报告页面，如果项圈检测频次低但问卷显示舔舐行为，需要给用户清晰说明"为什么数字看起来不高但建议就医"。

4. **L9-L10 不能依赖项圈判断**：极重度情况下行为可能反而减少，必须结合问卷和紧急就医推送。

5. **不要宣传"AI 精准诊断"**：我们做的是辅助评估和趋势追踪，最终诊断权在兽医。营销语言应强调"客观数据记录"和"趋势预警"。
