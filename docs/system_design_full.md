## 第一节：产品定位

### 1.1 核心定位

智能宠物项圈是一款**家庭健康监测设备**，专注于在家庭环境中对宠物进行持续、被动的健康数据采集与分析。

**核心设计原则：**

1. **居家监测，非GPS定位**：设备通过WiFi连接家庭网络，不搭载GPS模块。产品场景聚焦于宠物在家中的日常行为，而非户外轨迹追踪。
2. **最低佩戴年龄：8周（约2个月）**：幼犬骨骼和颈部肌肉发育尚未成熟，过早佩戴会造成颈椎压迫。8周以上幼犬颈围基本稳定，可安全佩戴。
3. **终身佩戴设计**：项圈设计为全天候佩戴，数据的价值在于长期连续性，断续佩戴会导致基线漂移和误判。
4. **每日批量评估，非实时报警**：系统在每天固定时间（默认凌晨2:00）对前24小时数据进行批量计算，输出健康评分。不设计实时推送，避免误报造成主人焦虑。
5. **数字孪生理念**：每只狗拥有属于自己的专属模型，评估结果基于该狗自身的历史基线，而非品种平均值或全量用户均值。

### 1.2 产品边界

**系统能做：**
- 检测抓挠行为的频率、强度、持续时间变化
- 追踪睡眠时长、入睡时间、睡眠稳定性
- 监测日常活动量与个体基线的偏差
- 感知体温异常与环境相关性
- 识别主人归家、分离焦虑等互动场景

**系统不能做：**
- 确诊任何疾病（设备输出仅为参考信号，不替代兽医诊断）
- 实时监测（数据处理为日批次，非秒级响应）
- 户外位置追踪（无GPS）
- 区分完全相同的行为模式（例如：无法区分"抓耳朵因过敏"vs"抓耳朵因耳螨"，只能检测到抓挠异常）

```
【场景示例 1-1】旺旺 - 为什么不做实时报警

旺旺今天下午3点连续抓挠47秒，单次事件强度较高。
如果系统实时推送报警，主人会立刻焦虑，可能中断工作赶回家。
但实际上旺旺在草地上玩耍后回到室内，这次抓挠是正常的"回家梳理行为"。
系统设计为批量评估：将这次事件纳入当日S1/S2计算，
与当日其他抓挠事件、温度数据、活动量综合分析后，
判断今日C-PVAS评分仍在正常范围（Z=-0.3），不触发通知。
→ 批量评估设计有效过滤了单次噪声事件，避免误报。
```

```
【场景示例 1-2】小黑 - 为什么最低年龄是8周

小黑是边牧，1岁，现在是第8天佩戴。
若产品允许6周幼犬佩戴：一只6周边牧颈围约为20-22cm，
但幼犬颈部肌肉群尚未充分发育，项圈的持续压力（约120-180g设备重量）
会影响颈椎第1-3节的正常发育。
系统设定8周（约56天）为最低年龄，此时幼犬颈部肌肉已初步成型，
颈围达到22-24cm，佩戴安全性大幅提升。
→ 8周门槛是安全性设计，非任意选取的数字。
```

```
【场景示例 1-3】花花 - 为什么是"终身佩戴"而非"按需佩戴"

花花10岁，有关节问题。主人在花花状态不好时才给她戴项圈。
问题：基线数据的有效性依赖于连续采集。
若花花只在"状态差"时佩戴：系统采集的数据样本存在选择性偏差，
算法会将"病态数据"误认为是花花的正常基线。
当花花某天偶尔戴上（状态稍好），系统反而会报告"活动量异常升高"。
终身连续佩戴确保了基线反映真实的个体行为模式，
评估结果才有意义。
→ 数字孪生模型需要连续数据流，断续佩戴会导致基线失真。
```

```
【场景示例 1-4】豆豆 - WiFi-only设计的适用场景

豆豆6岁法斗，典型的慵懒型家庭犬，每天95%的时间在家。
主人出门遛狗时间：早7:30出门，8:10回家（约40分钟）。
WiFi覆盖范围外的时间：约40分钟/天，占比约2.8%。
在此期间采集的数据：本地缓存在设备上，回到WiFi范围后批量上传。
数据丢失风险：接近零（设备本地存储支持72小时离线缓存）。
→ 对于典型家庭犬，WiFi-only设计足以覆盖99%的有效使用场景，
  同时节省了GPS模块的成本（约$15-20/件）和功耗（约30-40% battery节省）。
```

## 第二节：硬件传感器

### 2.1 传感器配置总览

| 传感器 | 型号类型 | 采样率 | 数据字段 | 用途 |
|--------|----------|--------|----------|------|
| 6轴IMU | 加速度计+陀螺仪 | 50Hz | ax,ay,az,gx,gy,gz | 行为分类、步态分析 |
| 颈部温度传感器 | 红外/接触式 | 1次/分钟 | neck_temp | 炎症检测、体温监测 |
| 环境温度传感器 | NTC热敏电阻 | 1次/5分钟 | env_temp | 环境修正、异常排除 |
| 环境湿度传感器 | 电容式湿度计 | 1次/5分钟 | env_humidity | 皮肤健康环境相关性 |

### 2.2 IMU传感器设计

**为什么选择6轴（而非9轴）？**
- 9轴IMU额外包含磁力计，用于绝对方向定位（指南针功能）
- 宠物行为分类**不需要绝对方向**，只需要相对运动模式
- 省去磁力计可降低成本约$0.8/件，并减少电磁干扰风险
- Yaw轴（偏航轴）确实无法从6轴IMU中解析，但在行为分类任务中Yaw轴信息贡献极小

**50Hz采样率的选择依据：**
- 宠物抓挠动作频率：约2-5Hz（每秒2-5次）
- 根据奈奎斯特定理，捕获5Hz信号需要至少10Hz采样率
- 50Hz提供了5×安全裕量，可以捕获细节动作特征
- 更高采样率（如200Hz）会增加功耗和数据量，无额外行为分类价值

### 2.3 温度传感器设计

**颈部温度（1次/分钟）：**
- 颈部皮肤温度是局部炎症的早期指标
- 1次/分钟的采样率足以捕获温度趋势，不需要更高频率
- 数据量：1440个点/天，约11KB/天（float32格式）

**环境温度/湿度（1次/5分钟）：**
- 环境参数变化缓慢，5分钟采样率已足够精确
- 主要用途是修正颈部温度读数（排除"因为天气热导致体温升高"的误判）
- 数据量：288个点/天，约2.3KB/天

## 第三节：数据处理管线

数据处理分为6个顺序步骤，每日运行一次（凌晨2:00批处理）。

```
原始IMU数据(50Hz) + 温度/湿度数据
        ↓
   Step 1: 佩戴检测
        ↓
   Step 2: 坐标归一化
        ↓
   Step 3: 行为分类
        ↓
   Step 4: 特征提取
        ↓
   Step 5: 每日评估
        ↓
   Step 6: 阶段化输出
```

### 3.1 Step 1：佩戴检测（Wear Detection）

**三种佩戴状态：**

| 状态 | 英文标识 | 判定条件 |
|------|----------|----------|
| 未佩戴 | NOT_WORN | IMU完全静止（加速度方差<阈值）+ 颈部温度接近环境温度（差值<1.5°C） |
| 松动佩戴 | WORN_LOOSE | 重力向量方差超过阈值（项圈在颈部滑动/晃动） |
| 正常佩戴 | WORN_NORMAL | 重力向量稳定 + 颈部温度高于环境温度（差值≥1.5°C） |

**设计原则：** 只有标记为 `WORN_NORMAL` 的时段数据才进入后续处理步骤。`NOT_WORN` 和 `WORN_LOOSE` 的数据被标记为无效，不参与评分计算。

---

```
【场景示例 3-1】花花 - NOT_WORN状态识别

花花的主人某天外出时将项圈摘下放在桌上：
- 桌上IMU数据（09:00-18:00）：
  加速度方差：σ² = 0.0003 g²（极低，完全静止）
  重力向量：恒定指向z轴负方向（项圈平放）
  颈部温度传感器读数：28.3°C
  环境温度：26.8°C
  差值：28.3 - 26.8 = 1.5°C（边界值，判定为NOT_WORN）
→ 系统标记09:00-18:00数据为NOT_WORN，
  该时段不计入花花当日有效数据，
  当日有效数据时长从24h降为15h，评分基于15h数据计算。
  若强制将桌上数据纳入计算，会产生大量"静止行为"，
  错误拉高睡眠时长统计，导致基线失真。
```

【场景示例 3-2】旺旺 - WORN_LOOSE状态识别

旺旺洗澡后项圈被主人戴松了：
- 重力向量方差：σ² = 0.089 g²（超过阈值0.05 g²）

- 颈部温度：38.5°C（正常体温，说明确实在狗身上）
→ 状态判定为WORN_LOOSE
  系统提示主人："检测到项圈佩戴松动，请重新调整，
  当前时段（14:30-15:45）数据质量不达标，已排除计算。"
  WORN_LOOSE数据不参与评分，避免项圈晃动被误分类为"高强度运动"。
```

```
【场景示例 3-3】小黑 - 睡眠中的WORN_NORMAL验证

小黑（边牧，1岁）深夜睡眠时段（23:00-06:30）：
- IMU数据：加速度方差σ² = 0.002 g²（低，但有呼吸微动）

- 温度差值：38.8 - 22.1 = 16.7°C（远超1.5°C阈值）
→ 判定为WORN_NORMAL
  该睡眠时段有效，纳入睡眠模块分析（主睡眠窗口检测）。
  小黑的主睡眠时长：7.5小时（23:00-06:30），质量良好。
```

```
【场景示例 3-4】豆豆 - 三种状态在一天中的分布

豆豆某天的佩戴状态分布：
- 00:00-07:00：WORN_NORMAL（睡眠，7小时）
- 07:00-07:30：WORN_LOOSE（主人帮豆豆洗脸时碰到项圈）
- 07:30-22:30：WORN_NORMAL（日常活动，15小时）
- 22:30-22:45：NOT_WORN（主人短暂取下项圈检查电量）
- 22:45-23:59：WORN_NORMAL（重新佩戴后睡眠）
有效数据时长：7h + 15h + 1.25h = 23.25小时（占比97%）
→ 当日数据质量良好，所有评分维度正常计算。
  若有效数据时长低于16小时，系统标记当日数据不足，不输出评分，
  避免基于残缺数据做出误判。
```

### 3.2 Step 2：坐标归一化（Coordinate Normalization）

**问题背景：** 项圈佩戴在狗的颈部，每次佩戴的旋转角度不同（可能旋转±45°），且狗低头、抬头时项圈相对重力的角度也在变化。如果直接用原始IMU坐标系分析，同一个"抓挠"动作在不同佩戴角度下的原始信号特征会截然不同，算法无法泛化。

**解决方案：实时重力向量对齐**

1. **低通滤波提取重力分量：** 使用截止频率0.5Hz的低通滤波器，从加速度计信号中提取缓慢变化的重力分量 `g_vec = [gx, gy, gz]`（约每0.1s更新一次）。
2. **计算旋转矩阵：** 根据当前估计的重力向量，计算将其旋转到标准重力方向 `[0, 0, -1g]` 的旋转矩阵 `R`。
3. **应用旋转变换：** 对加速度计和陀螺仪数据同时应用旋转矩阵 `R`，得到归一化的传感器数据。
4. **Yaw轴处理：** Yaw轴（绕重力轴旋转）在6轴IMU中无法确定绝对方向，但行为分类任务不需要Yaw绝对值，只需要Yaw的相对变化量（角速度），因此这一限制不影响分类精度。

**优点：** 无需出厂静态校准，项圈旋转佩戴也能正常工作，对用户完全透明。

---

```
【场景示例 3-5】旺旺 - 坐标归一化的必要性

旺旺的项圈今天佩戴时旋转了约30°（传感器x轴偏离水平面30°）。
原始IMU数据中一次抓挠：
  原始：ax=0.71g, ay=0.62g, az=0.34g（重力分量混入x、y轴）
  
经低通滤波估计重力向量：g_vec = [0.50g, 0.43g, -0.75g]
计算旋转矩阵R并应用后（归一化数据）：
  归一化：ax_n=0.12g, ay_n=0.08g, az_n=-1.02g
  (重力已完全归入z轴，x/y轴的读数纯粹代表水平运动)

行为分类模型接收归一化数据，
与旺旺昨天（项圈正常佩戴，旋转0°）的抓挠数据模式一致，
分类结果：SCRATCH，置信度0.92
→ 没有坐标归一化，同一个抓挠在不同佩戴角度下会产生不同的特征向量，
  导致分类准确率下降约15-20%，且需要每次佩戴重新校准。
```

```
【场景示例 3-6】花花 - 低头吃饭时的动态重力估计

花花（柴犬）在低头吃饭时，项圈相对重力方向会发生约30-45°的倾斜：
- 正常站立：g_vec ≈ [0.05g, 0.02g, -0.99g]
- 低头吃饭：g_vec ≈ [0.48g, 0.02g, -0.88g]（估算x轴倾斜约29°）
低通滤波器（截止0.5Hz）在约0.5-1秒内跟踪上这一变化：
  t=0ms：g_vec旧 = [0.05, 0.02, -0.99]
  t=500ms：g_vec更新 = [0.27, 0.02, -0.96]（过渡中）
  t=1000ms：g_vec稳定 = [0.48, 0.02, -0.88]（收敛）
在此期间的吞咽、咀嚼动作虽然会产生微小加速度信号，
但因0.5Hz低通滤波不会被计入重力估计，保证了旋转矩阵的准确性。
→ 动态重力估计允许系统在狗的各种姿势（站立、趴下、仰躺）下均正确工作。
```

```
【场景示例 3-7】小黑 - Yaw轴无法解析但不影响行为分类

小黑在玩耍时绕自身纵轴（Yaw轴）旋转了90°：
- 6轴IMU：可以检测到角速度 ωz = 45°/s（快速旋转）
- 但无法知道旋转后小黑面朝哪个方向（绝对Yaw角未知）
行为分类需要的特征：
  ✓ 角速度大小（ωz=45°/s → 快速旋转，归类为MOVEMENT）
  ✓ 加速度模式（高频抖动 → 排除SLEEP）
  ✓ 持续时间（0.8秒 → 短暂爆发）
  ✗ 绝对朝向（不需要！）
→ Yaw轴的绝对值对行为分类无贡献。
  系统使用角速度变化量（非绝对角度）即可正确分类小黑的玩耍行为，
  分类结果：MOVEMENT，置信度0.89。
```

### 3.3 Step 3：行为分类（Behavior Classification）

**当前支持的行为标签：**

| 标签ID | 标签名 | 描述 |
|--------|--------|------|

**未来扩展行为标签（规划中）：**
- LICKING（舔舐）
- HEAD_SHAKING（甩头）
- RUBBING（蹭墙/蹭地）
- RUNNING（奔跑）
- PLAYING（玩耍互动）

### 3.4 Step 4：特征提取（Feature Extraction）

#### PEB（抓挠事件）计算规则

- **PEB定义：** 持续时间≥3秒的连续SCRATCH行为片段
- **事件间隔要求：** 两个PEB之间的间隔必须≥30秒，否则合并为同一PEB
- **强度分级（基于峰值角速度）：**
  - Light（轻度）：峰值角速度 < P33阈值（Phase 2+个体化，默认80°/s）
  - Medium（中度）：P33 ≤ 峰值角速度 < P67阈值（默认150°/s）
  - Heavy（重度）：峰值角速度 ≥ P67阈值（默认150°/s）
- **W-PEB计算：** W-PEB = Light×1.0 + Medium×1.5 + Heavy×2.5

#### 主睡眠窗口检测

- 识别当天所有SLEEP片段
- **主睡眠窗口** = 最长的连续SLEEP片段
- **短暂小睡** = 所有持续时间<2小时的SLEEP片段

#### 颈部温度统计

- 当日颈部温度均值（neck_temp_mean）
- 当日颈部温度标准差（neck_temp_std，反映日内变化幅度）
- 与环境温度的相关系数（env_correlation）

【场景示例 3-14】小黑 - W-PEB加权的设计意义

小黑第8天数据，两种极端情况对比：
情况A：轻度抓挠多次
  Light PEB × 10次 = W-PEB = 10 × 1.0 = 10.0
  
情况B：重度抓挠少次
  Heavy PEB × 4次 = W-PEB = 4 × 2.5 = 10.0
  
两种情况PEB计数差异：10次 vs 4次（相差2.5倍）
两种情况W-PEB相同：10.0 = 10.0

从皮肤健康角度，情况B（少数重度抓挠）往往比情况A（多次轻度抓挠）
对皮肤造成更大伤害（爪子深度摩擦vs表面轻触）。
W-PEB通过加权正确区分了这两种情况：
  S1（抓挠频率，基于PEB计数）：情况A得分更低（更异常）
  S2（抓挠强度，基于W-PEB）：两者得分相同
→ S1+S2双维度设计捕获了不同模式的皮肤风险，单一计数无法做到。

### 3.5 Step 5：每日评估（Daily Assessment）

#### Z-score计算

每个维度的原始指标通过Z-score归一化：

```
Z = (今日值 - 基线均值) / 基线标准差
```

#### 基线更新规则（EWMA，α=0.1）

```
new_baseline_mean = α × today_value + (1-α) × old_baseline_mean
new_baseline_std = sqrt(α × (today_value - new_baseline_mean)² + (1-α) × old_baseline_std²)
```

**基线冻结条件：** 当触发"持续异常模式"时，停止更新基线，避免将病态状态纳入正常基线。

---

```
【场景示例 3-15】旺旺 - Z-score计算全流程

旺旺的抓挠基线（佩戴第45天，已稳定）：
  PEB_mean = 6.3次/天，PEB_std = 1.8次/天
  W-PEB_mean = 8.7，W-PEB_std = 2.4

今日实测（过敏症状发作）：
  今日PEB = 14次
  今日W-PEB = 21.5
  
S1 Z-score = (14 - 6.3) / 1.8 = +4.28（严重异常）
S2 Z-score = (21.5 - 8.7) / 2.4 = +5.33（严重异常）

由于Z-score超过阈值（Phase 3阈值为±1），S1、S2均大幅扣分。
同时触发基线冻结：后续EWMA更新暂停，
防止"今日PEB=14次"被纳入基线，导致基线被污染（从6.3上升到7.0）。
→ 基线冻结是防止"异常态漂移进基线"的关键机制。
  若不冻结，连续7天异常后旺旺的正常基线会被严重高估，
  之后即使恢复正常（PEB=6次），Z-score也会显示"低于基线"，
  系统误判为"症状好转超出预期"。
```

```
【场景示例 3-16】花花 - 基线更新的EWMA特性

花花佩戴第60天，关节问题导致活动量有缓慢下降趋势：
  第1天基线：movement_mean = 45分钟/天
  每天实际活动量：减少约0.5分钟/天
  第30天实际：约30分钟/天
  
EWMA（α=0.1）的追踪速度：
  α=0.1 意味着基线约需 1/0.1 = 10天更新半数权重
  30天后基线约追踪到：约38分钟/天（未完全追上真实值）
  Z-score：(30 - 38) / std = 持续轻微负值
  
这个设计是有意为之：EWMA不能追得太快，
否则会将"关节恶化导致的活动减少"认为是"新的正常"，
而不是持续报告"活动量低于基线"。
缓慢的α=0.1确保系统能持续感知花花活动量的长期下降趋势，
为主人和兽医提供有价值的长期变化信号。
→ EWMA的α值需在"追踪速度"和"稳定性"之间平衡，
  α=0.1在4-6周内形成稳定基线，对缓慢变化敏感，对日间噪声鲁棒。
```

### 3.6 Step 6：阶段化输出（Phase-based Output）

系统将佩戴历史分为4个阶段，每个阶段的输出精度不同：

| 阶段 | 佩戴天数 | 输出方式 | 评分范围示例 |
|------|----------|----------|-------------|
| Phase 0 | 1-3天 | ±3档范围 | "轻微偏高/正常/轻微偏低/中度偏高/中度偏低/..." |
| Phase 1 | 4-14天 | ±2档范围 | 5档输出 |
| Phase 2 | 15-30天 | ±1档范围 | 3档输出（偏高/正常/偏低） |
| Phase 3 | 31天+ | 精确单档 | 精确到具体分数 |

**设计逻辑：** 新用户数据少，基线不稳定，输出精度应该宽松，避免误报。随着数据积累，基线越来越准确，输出精度逐步提升。这是一种诚实的不确定性表达方式。

---

```
【场景示例 3-17】小黑 - Phase 0输出（第1-3天）

小黑第1天（全新用户）：
  PEB = 8次，W-PEB = 12.3
  没有历史基线，无法计算Z-score
  系统使用全局默认阈值（基于品种/年龄段的群体数据）：
    边牧1岁默认PEB正常范围：4-12次/天

  A) 天生抓挠偏少，8次对他来说偏高（1.5σ以上）
  B) 天生抓挠适中，8次就是正常水平
  C) 天生抓挠偏多，8次对他来说明显偏低
  Phase 0无法区分这三种情况。

```

## 第四节：数字孪生模型

数字孪生（Digital Twin）意味着系统为每只狗建立一个独立的数据模型，所有评估均基于该狗自身的历史数据，而非全体用户的平均水平。

### 4.1 个体基线维度（均使用EWMA，α=0.1）

#### 抓挠基线
- `scratch_peb_mean`：日均PEB次数
- `scratch_peb_std`：PEB日间标准差
- `scratch_wpeb_mean`：日均W-PEB
- `scratch_wpeb_std`：W-PEB日间标准差

#### 睡眠基线
- `sleep_main_duration_mean`：主睡眠时长（分钟）
- `sleep_onset_mean`：平均入睡时间（分钟，从午夜0点算）
- `sleep_wake_mean`：平均起床时间

#### 活动基线
- `activity_total_mean`：日均活动总时长
- `activity_light_ratio`：轻度活动占比
- `activity_medium_ratio`：中度活动占比
- `activity_heavy_ratio`：重度活动占比

#### 颈部温度基线
- `neck_temp_daily_mean`：日均颈部温度
- `neck_temp_intraday_std`：日内温度标准差

- `anxiety_index_mean`：焦虑指数均值

- `gait_acc_weekly_trend`：步态加速度信号的周级别长期变化量（间接反映体重变化）

### 4.2 阶段系统（Phase System）

| 阶段 | 天数 | 功能描述 |
|------|------|----------|
| Phase 0 | 1-3天 | 预热期，仅积累数据，不评分，输出±3档 |

| Phase 2 | 15-30天 | 基线趋于稳定，输出±1档 |
| Phase 3 | 31天+ | 基线成熟，精确输出单档 |

### 4.3 自适应强度阈值（Adaptive Intensity Thresholds）

- **Phase 0-1：** 使用全局默认阈值（基于品种/体重段的群体统计）
- **Phase 2+：** 基于该狗个人历史数据的百分位数自动校准
  - P33（33rd percentile）= Light/Medium强度分界
  - P67（67th percentile）= Medium/Heavy强度分界

## 第五节：皮肤健康模块（C-PVAS）

### 5.1 模块概述

C-PVAS（Canine Pruritic Vestibular Assessment System）是系统的核心功能模块，从6个维度综合评估宠物皮肤健康状态。总分100分，分数越高代表皮肤状态越健康。

### 5.2 六个评估维度

#### S1：抓挠频率（25分）
- 指标：当日PEB次数
- 计算：Z-score = (今日PEB - baseline_mean) / baseline_std
- 评分：基于Z-score映射到0-25分

#### S2：抓挠强度与持续时间（25分）
- 指标：当日W-PEB
- 计算：Z-score = (今日W-PEB - baseline_w_mean) / baseline_w_std
- 评分：基于Z-score映射到0-25分

#### S3：主睡眠质量（20分）
- 指标：主睡眠窗口内的抓挠比例 + 睡眠中断次数
- 关键设计：使用**动态主睡眠窗口**（当日最长连续SLEEP片段），而非固定22:00-06:00时间段
- 原因：不同家庭的作息时间不同，固定窗口会错误评估作息不规律的家庭

#### S4：颈部温度（10分）
- 指标：今日颈部温度均值与个人基线的偏差
- 计算：Z-score = (today_neck_temp_mean - baseline_neck_temp_mean) / baseline_neck_temp_std

#### S5：主人问卷（15分）
- L0-L10映射：
  - 0-9分 → L0，10-19→L1，20-29→L2，30-39→L3，40-49→L4，50-59→L5
  - 60-69→L6，70-79→L7，80-89→L8，90-99→L9，100→L10
- 问卷内容：皮肤发红？抓挠部位？分泌物？等主观观察

#### S6：环境修正（±5分）
- 分析近7天env_temp、env_humidity与PEB的相关性
- 若强相关（r>0.7），且当日环境指标处于高风险区间，给予环境折扣（最多+5分）
- 若环境恶劣但PEB未升高，给予额外正分奖励（皮肤耐受性强）

---

```
【场景示例 5-1】旺旺 - S3主睡眠窗口的关键性

旺旺的主人是程序员，作息偏晚：

  → 睡眠抓挠比例 = 1/7（总睡眠期PEB/总PEB），评估准确

### 5.3 持续异常模式（Persistent Abnormal Mode）

**触发条件（自动触发，无需用户操作）：**
- 连续N天Z-score超过阶段阈值
  - Phase 1：连续5天超过±2σ
  - Phase 2：连续4天超过±1.5σ
  - Phase 3：连续3天超过±1σ

**触发后的动作序列：**
1. **冻结基线：** 停止EWMA更新，防止异常态污染基线
2. **推送通知：** 根据严重程度推送产品推荐或建议就诊
3. **切换评估目标：** 从"检测异常"切换为"追踪趋势"（监测是否在好转）

**解除条件：** 连续7天Z-score回落至正常范围

---

```
【场景示例 5-5】旺旺 - 持续异常模式的完整触发和解除流程

旺旺5月过敏季节来临（Phase 3，第58天）：
  D+1（5/1）：PEB=11次，Z-score=+2.5（超阈值±1σ）
  D+2（5/2）：PEB=13次，Z-score=+3.5
  D+3（5/3）：PEB=14次，Z-score=+4.3（连续3天超阈值）
  → 触发持续异常模式

触发时刻动作：
  ① 基线冻结：PEB基线锁定在 mean=6.3，std=1.8（冻结前最后值）
  ② 推送通知（Day 3晚推送）：
     "旺旺连续3天抓挠频率异常升高（当前为正常水平的2.2倍）。
      建议：1. 检查家中是否有新的过敏原；
             2. 考虑使用低敏洗浴产品；
             3. 如症状持续请咨询兽医。"
  ③ 切换为趋势追踪：开始记录每日相对于冻结基线的Z-score变化趋势

主人就医，兽医开具抗过敏药物，开始治疗：
  D+7（5/7）：PEB=12次，Z-score=+3.1（仍高，但较峰值下降）
  D+10（5/10）：PEB=9次，Z-score=+1.5（明显改善）
  D+14（5/14）：PEB=7次，Z-score=+0.4（接近正常）
  D+15（5/15）：PEB=6次，Z-score=-0.2（正常范围）
  D+16-21：Z-score持续在[-0.5, +0.5]内（连续7天正常）
  → 解除持续异常模式，基线恢复EWMA更新

治疗效果报告推送：
  "旺旺皮肤状态已恢复正常（连续7天），
   本次异常持续21天（5/1-5/21），治疗后第11天开始改善。"
→ 持续异常模式实现了：
  ① 自动检测慢性皮肤问题（无需主人手动标记）
  ② 基线保护（冻结机制防止"病态均值"成为新基线）
  ③ 治疗效果追踪（切换为趋势模式后可量化好转速度）

## 第六节：日常生活模块

### 6.1 活动模块

**核心功能：**
- 与个体基线对比：今日活动是否达标（达标/不足/超量）
- 活动构成分解：步行/跑步/玩耍/休息时间占比
- 连续达标天数统计与游戏化成就
- 同品种同年龄段百分位排名

---

```
【场景示例 6-1】小黑 - 活动达标判定

小黑（边牧，1岁）Phase 3活动基线：
  activity_total_mean = 312分钟/天，std = 45分钟

今日活动数据：
  Light活动：142分钟（慢走、日常活动）
  Medium活动：98分钟（快走、轻度玩耍）
  Heavy活动：52分钟（奔跑、高强度玩耍）
  总计：292分钟

评估：
  Z-score = (292 - 312) / 45 = -0.44（轻微低于基线，但在正常范围）
  结论：达标（-1σ到+1σ范围内均为达标）
  
活动构成：
  Light: 49%，Medium: 34%，Heavy: 18%
  小黑历史分布：Light: 44%，Medium: 38%，Heavy: 18%（重度比例正常）

## 第七节：模块联动

以下6种跨模块联动机制确保系统各模块不是孤立计算，而是相互修正、相互增强。

### 7.1 联动机制一：焦虑抓挠折扣

**规则：** 主人离开后30分钟内检测到的抓挠事件，在S1/S2计算时给予折扣（默认折扣系数0.5）。

**原因：** 分离焦虑触发的抓挠是"情绪性抓挠"，不反映皮肤健康状态，若不折扣会导致S1/S2虚高。

---

```
【场景示例 7-1】旺旺 - 焦虑抓挠折扣的具体计算

旺旺某天主人09:00出门，旺旺产生明显分离焦虑：
  09:00-09:30（30分钟焦虑窗口内）：
    PEB = 8次，W-PEB = 12.0
    情绪模块焦虑指数：0.73（>基线+3σ，确认焦虑状态）
    
  09:30后（焦虑基本平复）：
    PEB = 3次，W-PEB = 4.5
    
  全天无折扣计算：PEB_total = 11次，W-PEB_total = 16.5
  
  S1 Z-score（无折扣）= (11 - 6.3) / 1.8 = +2.6（报告异常）
  
  应用焦虑折扣（系数0.5）：
    焦虑窗口PEB折扣：8 × 0.5 = 4次
    非焦虑PEB：3次
    折扣后有效PEB = 4 + 3 = 7次
    
    折扣后W-PEB = 12.0 × 0.5 + 4.5 = 10.5
    
  S1 Z-score（折扣后）= (7 - 6.3) / 1.8 = +0.4（正常范围）
  S2 Z-score（折扣后）= (10.5 - 8.7) / 2.4 = +0.75（正常范围）
  
→ 折扣机制防止了将分离焦虑误诊为皮肤问题。
  若无折扣，旺旺每次主人出门都会触发皮肤健康告警，
  导致主人焦虑和信任度下降。
```

---

### 7.2 联动机制二：运动后体温折扣

**规则：** 剧烈运动（Heavy级）结束后1小时内的颈部温度升高，在S4计算中给予折扣。

**原因：** 运动后体温升高是正常生理反应，不代表炎症。

---

```
【场景示例 7-2】小黑 - 运动后体温折扣

小黑某天下午高强度运动：
  15:00-15:45：Heavy级活动（45分钟高强度奔跑，加速度RMS>0.8g）
  
运动后体温变化：
  15:45：neck_temp = 39.6°C（运动刚结束）
  16:00：neck_temp = 39.3°C
  16:15：neck_temp = 38.9°C
  16:30：neck_temp = 38.5°C
  16:45：neck_temp = 38.2°C（接近基线38.1°C，恢复正常）
  
若不做运动折扣：
  16:00之前的高体温纳入S4计算
  S4 Z-score = (39.3 - 38.1) / 0.22 = +5.5（严重异常！）
  
应用运动后体温折扣（运动结束后1小时内的体温不纳入S4）：
  有效体温数据窗口：16:45之后（运动结束60分钟后）
  此时neck_temp = 38.2°C，接近基线
  S4 Z-score = (38.2 - 38.1) / 0.22 = +0.45（正常）
  
→ 运动折扣防止了将运动后正常体温升高误判为炎症信号，
  避免了频繁运动的活跃犬（如小黑、旺旺）S4评分系统性偏低。
```

---

### 7.3 联动机制三：复合预警增强

**规则：** 活动量下降+抓挠增加同时出现时，触发比单一维度更高级别的预警。

**原因：** 单一维度变化可能有多种解释，两个维度同向变化时疾病信号更强。

---

```
【场景示例 7-3】花花 - 复合预警早于单模块预警3天

花花某次皮肤+关节联合问题的早期阶段：

仅看活动量（D+1至D+3）：
  D+1: activity = 70分钟（基线81分钟，Z=-0.9，正常）
  D+2: activity = 62分钟（Z=-1.6，接近阈值）
  D+3: activity = 58分钟（Z=-1.9，刚过阈值，轻度告警）
  → 活动模块：D+3触发"轻度活动不足"通知

仅看抓挠（D+1至D+3）：
  D+1: PEB = 5次（基线3.8次，Z=+0.7，正常）
  D+2: PEB = 6次（Z=+1.3，接近阈值）
  D+3: PEB = 7次（Z=+1.8，接近阈值，不足以单独触发）
  → 抓挠模块：D+3 不触发告警（未超±2σ阈值）

复合预警规则：
  活动下降Z < -1.0 AND 抓挠升高Z > +1.0 → 触发复合预警
  
  D+1: 活动Z=-0.9（未达-1.0），不触发
  D+2: 活动Z=-1.6（达到）AND 抓挠Z=+1.3（达到）→ 触发复合预警！
  
→ 复合预警在D+2就触发，比单模块预警（D+3）早1天，
  比等待两个维度都达到独立告警阈值要早约2-3天。
  早期发现意味着花花可以更早得到干预，减少痛苦时间。
```

---

### 7.4 联动机制四：持续焦虑抑制基线更新

**规则：** 在持续焦虑状态（焦虑指数连续3天>基线+2σ）期间，S1/S2的基线EWMA更新权重从α=0.1降低到α=0.02。

**原因：** 焦虑期间的抓挠行为由情绪驱动，若以正常权重更新基线，会导致基线被"情绪性抓挠"污染。

---

```
【场景示例 7-4】旺旺 - 主人出差期间的基线保护

旺旺主人出差7天，旺旺持续分离焦虑：
  焦虑指数：连续7天均值0.61（基线0.23，超基线+4.8σ）
  日均PEB：9.2次（基线6.3次）
  
若正常基线更新（α=0.1）：
  7天后基线均值漂移：
  new_mean = 0.1×9.2 + 0.9×6.3 = 0.92 + 5.67 = 6.59（漂移0.29次）
  → 出差后基线被污染，"新正常"偏高，后续敏感度下降
  
应用焦虑抑制（α降为0.02）：
  7天后基线均值：
  new_mean ≈ 0.02×7×9.2 + (1-0.02×7)×6.3
           ≈ 1.288 + 5.422 = 6.31（漂移仅0.01次，几乎不变）
  
→ 焦虑抑制机制确保旺旺主人回来后，
  基线能准确反映旺旺健康状态下的正常抓挠水平，
  而非出差期间焦虑状态的平均值。
```

---

### 7.5 联动机制五：多维度治疗效果追踪

**规则：** 当检测到持续异常状态后（推测动物可能接受治疗），系统同时追踪皮肤评分、睡眠、情绪、活动4个维度的趋势，输出综合治疗效果报告。

---

```
【场景示例 7-5】旺旺 - 抗过敏药物治疗的多维度追踪

旺旺接受抗组胺药治疗（第5天开始用药）：

治疗前（D+1至D+5，基线冻结）：
  皮肤评分：52分
  主睡眠质量：61分（频繁抓挠中断）
  情绪评分：55分（不适导致情绪低落）
  活动量：165分钟（低于基线187分钟）

### 7.6 联动机制六：早期预警级联

**规则：** 特定维度的变化按时间顺序出现时（活动↓→睡眠↓→抓挠↑），系统识别为早期预警级联，比等待任何单一维度超阈值提前2-3天发现问题。

---

```
【场景示例 7-6】花花 - 关节炎急性发作的级联预警

花花某次关节炎发作的完整时间线：

D+1（周一）：
  活动量：62分钟（基线81分钟，Z=-1.6）← 第一个信号
  抓挠：PEB=4次（基线3.8，Z=+0.1，正常）
  睡眠：8.3小时（基线8.5，Z=-0.3，正常）
  系统状态：活动量轻微不足，无告警

D+2（周二）：
  活动量：54分钟（Z=-2.3）← 持续下降
  睡眠：7.6小时（Z=-1.1）← 开始下降
  抓挠：PEB=5次（Z=+0.7，轻微上升）
  复合预警规则：活动Z<-1.0 AND 抓挠Z>+0.5 → 触发级联预警！

D+2晚间系统推送（比传统单维度预警早2天）：
  "花花近2天出现活动减少、睡眠变短的迹象，
   抓挠轻微增加。这种模式可能是不适感的早期信号。
   建议今天仔细观察花花行走和起身姿势。"

D+3（周三）：
  活动量：45分钟（Z=-3.0，严重不足）
  睡眠：6.9小时（Z=-2.5，明显不足）
  抓挠：PEB=8次（Z=+2.5，显著升高）← 三维度同时异常
  → 若只看抓挠，今天才达到告警阈值（比级联预警晚1天）
  → 若只看活动，D+2才轻微告警

→ 级联预警比最慢的单维度告警早约2天，
  为花花的关节疼痛管理赢得了宝贵的早期干预窗口。
```

## 第八节：产品阶段规划

### 8.1 总体规划路线

```
Phase 1 (当前) → Phase 2 → Phase 3 → Phase 4
   皮肤健康      日常生活   数字孪生    生态扩展
  C-PVAS核心    监测深化   模型深化    行业连接
```

### 8.2 各阶段详述

#### Phase 1（当前）：C-PVAS皮肤健康
**核心功能：** 皮肤健康评分（S1-S6）、持续异常检测、治疗效果追踪  
**目标用户：** 有皮肤敏感/过敏史的宠物主人  
**产品价值：** 替代主观判断，提供客观连续监测

#### Phase 2：日常生活监测
**新增功能：** 活动模块、睡眠模块、互动模块、情绪日报  
**目标用户：** 关注宠物生活质量的全体用户  
**产品价值：** 从"医疗监测"扩展到"生活陪伴"

#### Phase 3：数字孪生深化
**新增功能：** 个性档案、体重趋势追踪、关节健康评估、心肺适能评估  
**目标用户：** 深度用户、运动型犬主人、老年犬主人  
**产品价值：** 全生命周期健康管理档案

#### Phase 4：生态扩展
**新增功能：** 兽医报告导出、社区功能（同品种对比）、宠物保险接入  
**目标用户：** 兽医诊所、保险公司、宠物社区  
**产品价值：** B端数据服务、保险精算数据、预防医学研究

```
