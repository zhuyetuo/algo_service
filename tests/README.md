# 测试说明

本目录包含两类测试：

| 类型 | 目录 / 文件 | 说明 |
|------|------------|------|
| 算法仿真测试 | `test_1_inference.py` / `test_2_assessment.py` / `test_3_baseline.py` | 端到端验证算法逻辑，输出可视化报告，无需数据库 |
| 单元测试 | `unit/` | pytest，覆盖各模块纯函数和接口，无需任何外部服务 |

---

## 算法仿真测试

### test_1_inference.py — 行为识别

```bash
python tests/test_1_inference.py
```

**流程：**
1. 生成 5 场景 × 180 天合成 IMU 数据，保存至 `tests/data/`
2. 用 S1/S2/S3 训练 LightGBM，模型保存至 `weights/behavior_lgbm.pkl`
3. 对全部 5 场景（含 S4/S5 未见场景）评估泛化能力
4. 输出准确率、分类报告、混淆矩阵、抓挠 F1

再次运行直接加载缓存 CSV，不重新生成数据（删除 `tests/data/` 可强制重建）。

**5 个测试场景：**

| 场景 | 行为分布 | 训练集 |
|------|---------|--------|
| S1 正常犬 | 运动 55% / 睡眠 40% / 抓挠 5% | ✓ |
| S2 活跃犬 | 运动 72% / 睡眠 25% / 抓挠 3% | ✓ |
| S3 安静犬 | 运动 20% / 睡眠 77% / 抓挠 3% | ✓ |
| S4 轻度皮肤病 | 抓挠 15% | 未见（泛化评估） |
| S5 重度皮肤病 | 抓挠 30% | 未见（泛化评估） |

### test_2_assessment.py — 皮肤健康评估

```bash
python tests/test_2_assessment.py
```

5 个场景验证评估引擎，涵盖正常、疾病、季节性、渐变、数据缺口等情况：

| 场景 | 内容 | 预期结果 |
|------|------|---------|
| A 正常 | 健康犬，无疾病 | 0 告警 |
| B 皮肤病 | 第 45–75 天发病（+10 抓挠） | ≥1 告警，恢复后消除 |
| C 季节性 | 夏季温度升高导致抓挠增加 | 0 误报（温度修正生效） |
| D 缓慢增加 | 抓挠 180 天线性增加 | 基线跟随，≤1 告警 |
| E 数据缺口 | 多段设备离线 + 后期疾病 | 无缺口误报，疾病期正常告警 |

输出：控制台诊断表格 + 折线图 `tests/test_2_assessment.png`

### test_3_baseline.py — 基线更新

```bash
python tests/test_3_baseline.py
```

4 个子测试验证 EWMA 基线更新算法的关键性质：

| 子测试 | 验证内容 | 通过条件 |
|--------|---------|---------|
| T1 正常收敛 | 90 天正常数据后基线误差 | < 1.0 |
| T2 异常渗透 | 30 天疾病期对基线的污染 | 偏移 < 3.0 |
| T3 温度系数 | 120 天学习温度-抓挠相关系数 | 系数误差 < 0.08 |
| T4 阶段转换 | 180 天完整生命周期 | 置信度达到 1.0，均值误差 < 1.5 |

输出：PASS/FAIL 汇总 + 图表 `tests/test_3_baseline.png`
