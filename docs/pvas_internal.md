# PVAS 算法工程内部技术文档

**面向对象：算法工程师 / ML 团队**
**版本：v1.0 | 2026-05-25**
**机密等级：内部文档，不对外发布**

---

## 一、硬件信号基础

```
传感器配置：
  IMU:  6轴，50Hz → ax, ay, az (m/s²), gx, gy, gz (°/s)
  颈温:  1次/分钟
  环温湿度: 1次/5分钟
  通信:  WiFi only, 无摄像头, 无GPS

当前行为分类器输出：
  UNKNOWN / MOVEMENT / SLEEP / SCRATCH
```

**核心约束**：项圈固定在颈部，所有信号均为颈部视角。离颈部越远的行为，信号越衰减、越难区分。

## 二、各行为类型可检测性详细分析

### 2.1 爪挠颈部（抓 - Scratch with paw at neck）

| 项目 | 内容 |
|------|------|
| **检测机制** | 爪子接触颈部产生高频振动（主要 az/ay 轴，10-25Hz 分量），伴随陀螺仪 gx/gy 轻微扰动。典型时域：短脉冲 0.5-3s，峰值加速度 >2g |
| **预估准确率** | 精确率 ~85%，召回率 ~80%（基于现有 SCRATCH 分类器） |
| **主要失效场景** | 1) 爪子挠非颈部区域（信号大幅衰减）2) 毛发浓密犬种（阻尼信号）3) 同一时段高强度运动后（基线噪声抬高）|
| **改进路径** | 数据标注强化分部位标签；对频次高的狗做个体基线校准 |

### 2.2 啃咬（啃 - Biting near collar region）

| 项目 | 内容 |
|------|------|
| **检测机制** | 啃咬颈/前胸时颈部扭转 + 周期性低频振动（1-5Hz），gx/gz 轴为主。与 SCRATCH 的主要区别：频率更低、持续时间更长（5-20s 一个连续段），加速度峰值略低但持续更久 |
| **预估准确率** | 精确率 ~65%，召回率 ~55%（目前并入 SCRATCH 类，未单独区分）|
| **主要失效场景** | 1) 啃远端部位（后腿、腹部）：信号极弱 2) 与玩玩具/咬骨头动作高度相似 3) 颈部以外部位啃咬基本无法区分 |
| **改进路径** | 需要细粒度数据标注（啃咬 vs 抓挠 vs 咬玩具），建议采集 300+ 个带时间戳视频-IMU 对齐样本；在特征层面添加连续段长度和频率分量特征 |

### 2.3 舔舐（舔 - Licking paws/body）

| 项目 | 内容 |
|------|------|
| **检测机制** | **当前基本无法检测**。舔爪时头部轻微低垂，颈部几乎静止。颈温传感器在大量舔舐时可能轻微升高（皮肤摩擦热），但信噪比极低 |
| **预估准确率** | <20%（基本与 UNKNOWN/SLEEP 混淆）|
| **主要失效场景** | 几乎全场景失效。这是当前最大的系统性盲区 |
| **改进路径** | **短期**：在问卷中重点采集舔舐信息；**中期**：添加喉部振动传感器（throat microphone 或压电振动传感器），舔舐时下颌运动会产生明显喉部振动；**长期**：摄像头方案 |

### 2.4 蹬腿挠身（蹬 - Rear leg kicking）

| 项目 | 内容 |
|------|------|
| **检测机制** | 后腿快速蹬踢时，躯干轻微摇晃，项圈受二次传导出现 ay/az 轴低幅振动。信号峰值通常 <0.8g，持续 0.5-2s 每次蹬踢 |
| **预估准确率** | 精确率 ~50%，召回率 ~40%（大型犬因躯干惯量大，传导更差）|
| **主要失效场景** | 1) 狗站立抓挠时（项圈信号偏弱，中小型犬更明显）2) 误判为普通站立/轻微移动 3) 大型犬（>30kg）传导衰减严重 |
| **改进路径** | 数据标注：需要按犬种/体重分层采集，估计需要每个体重段 200+ 样本；特征工程：计算躯干振动的周期性（蹬腿有节律）区分随机移动 |

### 2.5 甩头（甩头 - Head shake）

| 项目 | 内容 |
|------|------|
| **检测机制** | 快速左右旋转，gx 轴峰值 >200°/s，持续 0.2-0.8s，具有明显的对称性（左-右-左）。信号高度独特，几乎无歧义 |
| **预估准确率** | 精确率 ~90%，召回率 ~85% |
| **主要失效场景** | 1) 甩耳（比甩头更小范围）可能被漏检 2) 侧翻/打滚时误判为甩头 |
| **改进路径** | 当前准确率已较高；细化可区分甩头（对称大幅）vs 甩耳（单侧小幅，gx 旋转幅度更小）|

### 2.6 磨屁股（磨屁股 - Butt dragging）

| 项目 | 内容 |
|------|------|
| **检测机制** | **完全无法检测**。动作发生在臀部，项圈位于颈部，无任何有效信号 |
| **预估准确率** | ~0% |
| **主要失效场景** | 全部 |
| **改进路径** | 唯一可行方案：尾部/臀部附加传感器，或摄像头。问卷补充是目前唯一的信息来源 |

## 三、各 PVAS 等级算法分析（L0–L10）

以下分析基于 24h 窗口，假设问卷已完整填写。特征值为参考范围，需基于实际采集数据校准。

### L0 — 正常

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 事件计数 = 0，SLEEP 占比 >40%（成年犬），MOVEMENT 规律且连续，夜间无中断 |
| **可靠检测** | 完全可靠。负类（无瘙痒）是基线建立最容易的状态 |
| **漏检风险** | 极低舔舐（L1 边界）可能被归为 L0 |
| **混淆风险** | L0 vs L1：区分取决于计数阈值设定 |
| **置信度** | **HIGH** |

### L1 — 极微痒

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 1-2，IMU 峰值幅度低（<1.5g），持续时间 <2s，SLEEP 无中断，MOVEMENT 正常 |
| **可靠检测** | 抓挠行为检测可靠；舔舐型 L1 完全漏检 |
| **漏检风险** | 如果 1-2 次行为全为舔舐 → 项圈计数=0，错分为 L0 |
| **混淆风险** | L1 vs L0、L1 vs L2（计数边界敏感）|
| **置信度** | **HIGH**（纯抓挠型）/ **LOW**（纯舔舐型）|

### L2 — 非常轻度

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 3-5，峰值幅度轻中（1-2g），SLEEP 完整，MOVEMENT 白天正常 |
| **可靠检测** | 抓挠计数可靠，睡眠正常性可靠 |
| **漏检风险** | 若部分行为为舔舐，项圈计数系统性偏低 |
| **混淆风险** | L2 vs L3（计数 5 vs 6 的边界）|
| **置信度** | **HIGH** |
| **皮肤维度** | 问卷询问皮屑/干燥，应为阴性或极轻微 |

### L3 — 轻度偏轻

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 6-8，开始出现舔爪/蹭地（但项圈基本漏检这两种），甩头偶发，SLEEP 白天偶有短暂中断（<5min/次），夜间无中断 |
| **可靠检测** | 甩头、爪挠可靠；舔爪/蹭地基本漏检 |
| **漏检风险** | **较高**：L3 的描述中明确包含"多为舔爪/蹭地"，这两种行为项圈均弱检测，导致项圈评估结果系统性偏向 L1-L2 |
| **混淆风险** | L3 很容易被低估为 L1-L2；也容易与 L4 混淆（计数边界 8 vs 9）|
| **置信度** | **MEDIUM**（需要问卷强制补充）|

### L4 — 轻度

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 9-12，峰值幅度中（1.5-3g），舔咬增多（项圈部分检测），夜间 SLEEP 中断 0-1 次，白天 MOVEMENT 基本连续但偶有短停（1-3 min）|
| **可靠检测** | 行为计数可靠；夜间睡眠中断（如有）可靠 |
| **漏检风险** | 舔咬动作的漏检；进食减少弱信号 |
| **混淆风险** | L4 vs L3（计数 9 vs 8）；L4 vs L5（作息影响程度判断主观性较强）|
| **置信度** | **MEDIUM-HIGH** |

### L5 — 轻中度

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 13-16，开始出现阵发模式（3-5次/阵，阵间隔<30min），SLEEP 中断 1-2 次/晚（每次 5-20min），白天活动偶尔被短暂打断 |
| **可靠检测** | 阵发模式检测：可计算 SCRATCH 事件的时间聚集性（cluster coefficient）。夜间中断次数可靠 |
| **漏检风险** | 皮肤维度（小片脱毛、明显皮屑）完全依赖问卷 |
| **混淆风险** | L5 vs L4（夜间"偶尔"vs"1-2次"的边界模糊）；L5 vs L6（阵发频率判断）|
| **置信度** | **MEDIUM** |
| **皮肤维度** | 问卷必须询问脱毛、皮屑，否则 L5 可能被低估为 L4 |

### L6 — 中度

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 17-22，阵发频繁（间隔<15min），每次持续 10-30s，SLEEP 夜间多次中断（2-4次），白天 MOVEMENT 段长度缩短（玩耍中途停止），进食窗口异常（活动量低于基线 >30%）|
| **可靠检测** | 频率和强度检测可靠；睡眠碎片化指标可靠（SLEEP_FRAGMENTATION_INDEX）；白天活动模式异常可靠 |
| **漏检风险** | 皮肤维度（红斑+明显脱毛+小丘疹）完全无法检测；"分心仍会痒"这一状态需要问卷确认 |
| **混淆风险** | L6 vs L5（行为频率边界 16/17），L6 vs L7（睡眠影响程度）|
| **置信度** | **MEDIUM** |

### L7 — 中度偏重

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 23-30，反复在同一时间窗口出现高强度信号（提示同部位反复啃咬），SLEEP 严重碎片化（夜间中断>4次，单次中断持续>20min），白天 MOVEMENT 段极短（<10min/段），整体活动能量下降 |
| **可靠检测** | 睡眠碎片化最可靠（夜间>4次中断为强信号）；高频持续抓挠可靠 |
| **漏检风险** | "情绪烦躁"无法从IMU直接量化；皮肤结痂和轻度增厚完全无法检测；此阶段狗狗可能因疲惫而部分行为减少（开始出现低估风险）|
| **混淆风险** | L7 vs L8：计数边界（30 次）本身在一天中难以精确，行为持续时长成为关键区分特征 |
| **置信度** | **MEDIUM** |

### L8 — 重度

| 项目 | 内容 |
|------|------|
| **预期信号** | SCRATCH 计数 >30，出现持续 1-5 分钟的长阵发段（SCRATCH_SEGMENT_DURATION > 60s），SLEEP 极度碎片化（夜间有效睡眠<4h），进食窗口内活动量极低，白天总活动量可能开始下降（力竭效应）|
| **可靠检测** | 长阵发段持续时间可靠；睡眠严重不足可靠；整体活动下降趋势可靠 |
| **漏检风险** | **严重**：此阶段皮肤外观（大片脱毛、结痂、色素沉着、小糜烂）占 30% 权重，完全无法检测。如问卷不完整，L8 容易被低估为 L5-L6 |
| **混淆风险** | 此阶段狗狗因力竭开始减少挣扎，计数可能不超过 30 → 与 L7 混淆 |
| **置信度** | **MEDIUM-LOW** |
| **关键风险** | 详见第五节系统性偏差分析 |

### L9 — 极重度

| 项目 | 内容 |
|------|------|
| **预期信号** | 理论上行为极频繁；**实际上**：狗狗可能因极度疲惫而出现活动量骤降，SLEEP 状态标签可能误判（静止不等于睡眠，但传感器难以区分），行为计数可能反而低于 L7-L8 |
| **可靠检测** | 几乎无可靠的正向信号；仅凭项圈无法可靠区分 L9 和 L3 |
| **漏检风险** | **极高**。L9 对应的皮肤状况（广泛破皮、渗液、厚痂、继发感染）是主要评分依据，完全无法从项圈获取 |
| **混淆风险** | L9 力竭期可能被误判为 L2-L4（行为减少误认为好转）|
| **置信度** | **LOW** |

### L10 — 极致重度

| 项目 | 内容 |
|------|------|
| **预期信号** | 理论上持续高强度；实际：需要物理约束 → 信号极度混乱，无法建模 |
| **可靠检测** | 无 |
| **置信度** | **CANNOT**（纯项圈无法评估，必须兽医介入）|

## 四、30% 皮肤外观维度的根本性缺口分析

### 4.1 为什么这是最难的部分

PVAS 皮肤评分维度的核心是**视觉形态学信息**：

```
皮肤评分特征（无法从 IMU 获取）：
  L0-L2: 无异常 / 极轻微皮屑
  L3-L4: 局部轻微发红 / 皮屑增多
  L5-L6: 明显发红 / 小片脱毛 / 小丘疹
  L7:    红斑 + 脱毛 + 结痂小点 / 轻度增厚
  L8:    大片脱毛 + 红斑 + 结痂 + 色素沉着 / 小糜烂
  L9:    大面积破皮 / 渗液 / 厚痂 / 继发感染
  L10:   广泛破溃 / 糜烂 / 渗血 / 重度感染
```

以上每一项都需要视觉或触觉评估，IMU + 温度传感器的组合从物理原理上无法提供这些信息。

### 4.2 颈温传感器作为皮肤炎症代理信号的局限性

颈温传感器（1次/分钟）理论上可以反映局部炎症，但存在以下限制：
- **仅覆盖颈部**：大多数过敏性皮炎的皮损好发于腹部、腋下、爪部，与颈温无关
- **信噪比低**：环境温度变化（±2°C）远大于炎症引起的局部温差（+0.3-0.8°C）
- **延迟效应**：皮肤慢性炎症不一定反映在即时温度上
- **结论**：颈温传感器对皮肤外观评估的贡献极低，不建议作为主要特征

### 4.3 问卷补偿策略及其局限

当前方案：通过结构化问卷让主人描述皮肤状况。

| 问卷覆盖能力 | 评估 |
|--------------|------|
| L0-L2 皮肤正常 | 主人通常能正确判断（无异常） |
| L3-L4 轻微发红/皮屑 | 部分主人能识别（毛发浓密犬种困难） |
| L5-L6 脱毛/丘疹 | 多数主人能发现 |
| L7-L8 结痂/色素沉着/糜烂 | 主人能发现，但可能描述不精确 |
| L9-L10 渗液/继发感染 | 主人通常会意识到严重性 |

**问卷的核心问题**：
1. **主人观察频率低**：每天仔细检查皮肤的主人是少数
2. **毛发覆盖**：金毛、哈士奇等厚毛犬种的腹部皮肤很难被主人主动检查
3. **问卷填写率**：如果强制填写，质量下降；如果可选，则填写率低

### 4.4 关键风险：重症低估（Underestimation at High Severity）

最危险的误判场景：

```
真实状态：L8（大片脱毛+结痂+色素沉着）
  ↓ 皮肤维度满分段 → 扣除 30% 权重
  
项圈信号：狗狗因皮肤疼痛减少剧烈挣扎，计数 18-22 次
  ↓ 行为维度对应 L6
  
作息影响：睡眠碎片化，但白天活动也低（因疼痛不动）
  ↓ 对应 L5-L6
  
算法输出：L5-L6（严重低估 2-3 个等级）
```

这个风险在临床上最危险，因为 L8 需要当天就医，而算法给出 L5-L6 用户可能只做常规预约。

### 4.5 硬件解决方案评估

| 方案 | 效果 | 成本 | 时间线 |
|------|------|------|--------|
| 定期拍照（App 引导）| 覆盖主要皮肤状况，但依赖用户行为 | 低 | 立即可行 |
| 摄像头（项圈集成）| 最完整，但项圈体积/功耗/隐私问题 | 极高 | 2年+ |
| 摄像头（独立设备/家庭摄像头联动）| 效果好，部署灵活 | 中 | 6-12个月 |
| AI 图像识别（拍照+CV模型）| 可量化皮肤评分，但需要大量标注数据 | 中-高 | 12-18个月 |

**推荐短期方案**：App 内置皮肤拍照引导（每周 1 次），结合简单的皮肤问卷，可将皮肤维度覆盖率从 0%（纯项圈）提升到 ~80%（问卷）。

## 五、系统性偏差分析

### 5.1 舔舐型犬只系统性低估

```
偏差方向：低估（算法评分 < 真实 PVAS）
幅度估计：低估 1-3 个等级
影响犬群：以舔舐为主要应对行为的犬只
           → 常见于特应性皮炎（atopic dermatitis）早中期
           → 猫的习性（某些犬种表现为 cat-like grooming）
           → 比熊、贵宾等小型犬多见

根本原因：
  - 舔爪：颈部几乎静止 → SCRATCH 计数=0
  - 舔腹/舔爪间皮肤：同上
  - 算法只计算爪挠、甩头等有明确 IMU 特征的行为

缓解措施：
  1. 问卷中明确询问"是否频繁舔爪/舔特定部位"
  2. App 提示：如问卷舔舐频率高但项圈计数低，发出"数据差异警告"
  3. 喉部振动传感器（根本解决）
```

### 5.2 力竭/习得性无助型犬只系统性低估

```
偏差方向：极度低估（算法评分 << 真实 PVAS）
幅度估计：低估 3-5 个等级（最危险的偏差）
影响犬群：慢性重症瘙痒（真实 L7-L10）的犬只

现象：
  - 长期剧烈瘙痒后，狗狗体力耗尽，反而减少挣扎
  - 皮肤疼痛加重（破皮、感染）导致即使痒也不敢大幅度抓
  - 行为计数下降，项圈误认为"好转"

识别特征（可检测）：
  - 总体活动量骤降（MOVEMENT 占比 < 正常基线 40%）
  - 睡眠 vs 静止无法区分（狗躺着不动可能是睡眠，也可能是痛到不敢动）
  - 进食窗口无任何活动 → 可能无法进食
  - 趋势图：抓挠计数从高峰开始下降但皮肤问卷评分上升 → 高危信号

算法对策：
  - 设计"行为-皮肤背离检测器"：如果皮肤问卷评分上升但行为计数下降，触发高危警告
  - 在报告中明确提示："行为减少不等于好转，请结合皮肤状况判断"
  - 连续 3 天活动量低于基线 50% + 任意皮肤评分 ≥ L5 → 强制推送就医提醒
```

### 5.3 高基线活动量犬只系统性高估

```
偏差方向：高估（算法评分 > 真实 PVAS）
幅度估计：高估 1-2 个等级
影响犬群：工作犬、运动犬、高度活跃犬种（边牧、柯基、哈士奇等）

根本原因：
  - 高强度运动产生的 IMU 信号与抓挠信号在某些轴上重叠
  - 运动后喘气/抖毛被误分类为 SCRATCH
  - 正常奔跑中途停下短暂抓挠，难以从运动背景中分离

缓解措施：
  1. 个体基线建立（前 7 天为 baseline window）
  2. 上下文感知：运动后 5 分钟内的 SCRATCH 事件降低权重
  3. 犬种分层模型（或犬种作为特征输入）
  4. 环境温度修正：高温天气运动量自然减少，基线需要季节性调整
```

### 5.4 夜行型/倒班型作息犬只偏差

```
偏差方向：双向不确定
影响犬群：主人夜班 → 狗作息完全倒置；流浪犬收养后作息未稳定

根本原因：
  - SLEEP 分类器假设正常作息（夜间为主要睡眠期）
  - 白天睡眠被误判为 UNKNOWN/MOVEMENT（因为白天活动噪声多）
  - 夜间活跃被误判为作息异常（实际是正常）

缓解措施：
  1. 个体化作息基线（不假设固定睡眠时间）
  2. 根据前 7 天活动分布自动识别主睡眠期
  3. 注册时询问主人"狗狗主要睡眠时间"作为先验
```

## 六、各 PVAS 区间算法置信度汇总

### 6.1 置信度评级

| PVAS 区间 | 描述 | 整体置信度 | 主要风险 |
|-----------|------|------------|----------|
| **L0-L2** | 正常到极轻微 | **HIGH** | 舔舐型极轻度漏检（L0→L1 误判）；整体影响小 |
| **L3-L5** | 轻度到轻中度 | **MEDIUM** | 舔舐/蹭地漏检导致系统性低估；行为与皮肤评分边界模糊 |
| **L6-L8** | 中度到重度 | **MEDIUM-LOW** | 皮肤维度 30% 缺口显著影响评分；力竭效应开始出现 |
| **L9-L10** | 极重度到极致重度 | **LOW / CANNOT** | 行为悖论（力竭）；皮肤完全依赖视觉评估；项圈单独无法评估 |

### 6.2 可探测的关键特征信号（Feature Engineering 重点）

# 推荐特征列表（按重要性排序）

# Tier 1: 直接可靠

## 七、模型训练需求分析

### 7.1 细粒度行为分类模型

| 目标行为 | 当前状态 | 所需样本量（最小） | 标注方法 | 架构变更需求 |
|----------|----------|---------------------|----------|--------------|
| 抓挠（爪挠颈部）| 已有（SCRATCH 类）| 扩充 200 例/犬种 | 视频+IMU 时间对齐 | 无需重新设计 |
| 啃咬（颈部附近）| 并入 SCRATCH | 300+ 例（含多犬种）| 视频逐帧标注+IMU对齐 | 增加输出头 |
| 舔舐 | 基本缺失 | 500+ 例 | 需要振动传感器数据为主，IMU为辅 | 新传感器则需新架构 |
| 蹬腿挠身 | 弱 | 按体重段各 200+ 例 | 视频+IMU，分体重层 | 轻微调整 |
| 甩头 | 已有（较好）| 扩充 100 例/犬种 | 简单标注 | 无需变更 |
| 磨屁股 | 无 | 需要尾部传感器 | 新硬件 | 新架构 |

### 7.2 标注方法论建议

```
标注流程：
1. 同步采集：摄像头（60fps）+ 项圈 IMU（50Hz）时间戳对齐（误差<50ms）
2. 主标注：行为起止时间 + 行为类型（7类：抓/啃/舔/蹬/甩头/磨屁股/其他）
3. 部位标注：接触部位（颈/耳/爪/腹/后躯）
4. 强度标注：1-3（轻/中/重）

关键要求：
  - 每只狗至少 4 小时连续标注（覆盖不同活动状态）
  - 犬种分布：小型犬/中型犬/大型犬各至少 30 只
  - 状态分布：健康犬 / 轻度瘙痒犬 / 重度瘙痒犬 各占约 1/3
  - 不同环境（室内/室外，地板/草地/沙发）各有代表
```

### 7.3 模型架构建议

```
当前架构：时序 CNN / LSTM，输入 IMU 6轴，输出 4 类

建议升级方向（按优先级）：
1. 扩展输出为 7+ 类（增加啃咬、甩耳等细粒度类别）
   → 需要对应标注数据，架构改动小

2. 增加颈温作为辅助输入（多模态融合）
   → 对皮肤炎症代理信号的提升有限，优先级低

3. 个体化基线层（per-dog embedding）
   → 解决高基线犬只的高估问题，优先级中

4. 时序异常检测模块（力竭/背离检测）
   → 独立规则层叠加于主模型之上，实现相对容易

5. 舔舐专用模型（若引入振动传感器）
   → 需要全新数据 pipeline 和模型分支
```

## 八、具体失效场景案例

### 案例一：以舔舐为主的比熊（低估型）

```
真实情况：
  - 5岁比熊，特应性皮炎
  - 每天舔爪 12-15 次，舔腹部 5-6 次，爪挠颈部仅 2-3 次
  - 夜间偶有 1 次中断
  - 爪部皮肤轻微发红，轻度皮屑
  - 真实 PVAS ≈ L5

项圈检测：
  - SCRATCH 计数：3（仅爪挠颈部被检测到）
  - 夜间中断：1 次
  - 总体活动量正常

算法输出：L1-L2（行为计数极低，作息几乎正常）

低估量：约 3 个等级
风险：用户看到 L1-L2 不会就医，但 L5 已需要干预

缓解：问卷中"舔爪频率"字段为关键。如问卷填写 >10次/天，
      算法应强制上调评估结果至 L4+，并提示就医
```

### 案例二：严重湿疹力竭期边牧（极度低估型）

```
真实情况：
  - 3岁边牧，全身性特应性皮炎急性发作
  - 2天前：抓挠 35+ 次，夜间频繁中断（真实 L8）
  - 今天：皮肤破溃疼痛，不敢大幅度挣扎，仅轻触式应对
  - 抓挠次数降至 12-15 次，但皮肤状况更差
  - 真实 PVAS 今天仍 ≈ L8-L9

项圈检测（今天）：
  - SCRATCH 计数：14（下降）
  - 夜间中断：2 次（减少，因为不敢大动）
  - 白天活动量：骤降 60%（太痛不动）

算法输出（仅今天数据）：L4-L5（行为减少误认为好转）

低估量：3-4 个等级
风险：算法判断"好转趋势"，用户减少警惕，延误治疗

缓解：
  1. 必须使用趋势数据，而非单日数据（昨天 L8 → 今天行为突降 = 高危）
  2. 活动量骤降（<50% 基线）触发独立警报，不依赖行为计数
  3. 皮肤问卷："是否发现新的破皮/渗液" → 如是，强制高危评级
```

### 案例三：高活跃哈士奇运动误判（高估型）

```
真实情况：
  - 2岁哈士奇，健康，偶有轻微皮屑（真实 PVAS ≈ L1-L2）
  - 每天 2 次高强度运动（奔跑、跳跃）
  - 运动后习惯抖毛/挠头 2-3 次
  - 运动期间偶尔抓痒 1-2 次（正常范围内）

项圈检测：
  - 运动后抖毛：被分类为 SCRATCH（甩头特征相似）× 6次
  - 实际抓挠：3 次
  - 算法计数：约 9-12 次（实际只有 3 次）

算法输出：L4（计数误判）

高估量：约 2-3 个等级
风险：不必要的就医建议，用户信任度下降

缓解：
  1. 运动前后 10 分钟内的 SCRATCH 类事件降低权重
  2. 哈士奇/高活跃犬种个体基线校准（前 7 天建立正常计数基线）
  3. 甩头专项区分：甩头（头部旋转 gx 主导）vs 抖毛（全轴高频）
```

### 案例四：问卷未填写的中度病例

```
真实情况：
  - 金毛，7岁，中度过敏（真实 PVAS ≈ L6）
  - 行为：18 次抓挠，2 次甩头，夜间 3 次中断，白天活动减少
  - 皮肤：腹部红斑 + 轻度脱毛（不影响行为计数，但占 30% 权重）
  - 用户没有填写皮肤问卷

项圈检测：
  - 行为维度估算：对应 L5-L6 ✓
  - 作息维度：对应 L5-L6 ✓
  - 皮肤维度：缺失（0分）

算法输出：
  - 如果皮肤维度强制设 0：总分降低 30%，输出约 L4
  - 如果皮肤维度用中位数填充：输出约 L5

低估量：1-2 个等级
风险：用户不就医，皮肤问题持续恶化

缓解：
  1. 问卷未完成时，在评估结果页面显示"置信度：低"
  2. UX 强制引导：行为计数 ≥ L4 时，不完成皮肤问卷则无法查看完整报告
  3. 算法侧：输出置信区间而非单点值（例如 "L4-L6"，皮肤问卷完成后可收窄）
```
